## 2. 최종 Top3 완성안 (루프 5)

공통 기준:
- TOFU 톤이다. 관점 전환은 하되 허위 공포와 제품 설명은 쓰지 않는다.
- 직설형으로 쓴다. 후킹 한 줄에 누가, 어떤 문제를 겪는지 담는다.
- 법률 판단·소유권은 단정하지 않는다.
- 숫자는 질문이나 '예시'로만 쓴다.

## 4. 원장 변경 사항

- 명예의 전당 재채점: 이번 실행 점수를 이어 붙인 행은 다음과 같다(명확성 ±5 포함).
  - '사람 선택' 교안도 같이 나가나요: 76.4
  - '사람 선택' 먼저 안심시키는 법: 29.0
  - 그 반 교안: 85.0 / 80.9 / 84.4 / 85.0 / 85.3
  - 인기 강사: 83.8 / 81.8 / 78.2 / 79.4 / 76.1
  - 학부모 단톡방: 70.7 / 72.2 / 80.3 / 64.5 / 72.2
  - 따라 나간 학생: 76.7 / 77.3 / 77.0 / 60.0
  - 아픈 날: 74.6 / 78.5 / 70.1 / 83.8 / 64.8
- 명예의 전당 신규: 없음. 2위(최고 80.6)와 3위(최고 76.7)를 넣으면 12행이 되고, 정원 규칙상 최고점이 가장 낮은 이 두 행이 빠진다. '사람 선택' 2행 + 8행 그대로이며 순서 변동은 없다.
- 장점 풀(상한 30 유지): 줄 수는 그대로 두고 "과거형 측정 질문" 줄에 이번 근거(인기 강사 따라 나간 학생 68.9 → 80.6)를 덧붙였다.
- 피할 패턴(상한 20 유지): 줄 수는 그대로 두고 "퇴사·교안(P3) 후보가 루프의 절반을 넘으면" 줄에 이번 결과(P3 5~8개로도 루프 2~4 Top3 모두 P3, 퇴사 외 최고 70.4~75.2)를 덧붙였다.
- 실측 피드백 섹션은 건드리지 않았다.
- 실행 기록에 2026-11-12 행을 더했다.
