## 4. 원장 변경 사항

- 명예의 전당: 완성안 중 M-L4-04(75.0)와 M-L5-15(71.1)를 올렸다. M-L4-14(69.9)는 기준에 못 미쳐 올리지 않았다. 같은 후킹의 재채점은 기존 행에 덧붙였다(다시보기 없어요 / 73.8 / 69.9 / 63.9, 견적서 PC / 73.5 / 73.5 / 73.8 / 73.5, 녹화 파일이면 됩니다 / 60.4, 90일 파일럿 / 69.2 / 66.6, 다시보기 있다면서요 지점 / 67.2). 정원 10개를 맞추려고 70.8점 이하 2개(다시보기 있다면서요 지점마다 달랐다, 새 칠판 시범으로는 본사 설득 안 돼요)가 밀려났다.
- 장점 풀: 숫자 대비 사물 1줄을 더하고, 오래되고 이번에 쓰이지 않은 "시점 지정" 1줄을 뺐다(상한 30 유지). 피할 패턴: 변경 없음(상한 20). 실측 피드백 섹션은 건드리지 않았다.
- 점수 주의: 같은 후킹이 심사위원에 따라 크게 흔들려 명예의 전당 최고점 순서는 참고용이다.
