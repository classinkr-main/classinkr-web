지금 화면의 문제

  • '캠페인'이 세 가지 — 한눈에·상세의 스코어보드는 우산 캠페인 18개(전부 2~7월 Meta, 15개 휴면), 데이터 › Meta 는 라이브 Meta, 데이터 › Google 은 정적 계획표. 채널→캠페인 계층이 어디에도 없다.
  • 구글이 첫 화면에 없다 — 한눈에 광고비·CPL 은 Meta USD 만. 395 의 운영 캠페인 2개(₩41,169)는 데이터 층 맨 아래, 그것도 API 표는 로컬·미설정이면 숨는다.
  • Google 섹션이 11/3 기록에 멈춤 — '924 집행 중 · 잔액 ₩0 · C1~C4 승인 대기'. 실제는 924 일시중지(11/6), 디맨드젠 시험 운영, C4 보류.
  • 성과가 플랫폼 숫자 — 스코어보드 리드는 Meta 리포트(206), 구글은 전환 칸(0, 동의 뒤에만 태그). DB 리드 짝짓기는 없다 — 그런데 Meta 리드 217건은 utm_campaign 이름으로 217/217 캠페인에 붙는다.
  • 맨 위 판정이 9/28 AI 브리핑 — 5주 지난 문장이 첫 줄. (이번 범위 밖, 따로 고칠 후보)
