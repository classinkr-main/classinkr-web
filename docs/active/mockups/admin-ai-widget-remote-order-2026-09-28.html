확인하지 않은 오더는 15분 뒤 자동으로 만료된다. 전체 이력은 AI 올인원 탭의 오더함에서 본다.

⌘J
  • 1첫 화면. 인사, 확인 대기 알림, 화면별 추천. 추천은 정적 목록이고 오른쪽 글자가 오더 등급이다.
  • 2화면 맥락. 지금 보는 경로와 열린 대상을 읽어 「이 학원」을 해석한다. 「맥락 끄기」를 누르면 화면과 무관하게 묻는다.
  • 3진행 표시. 답을 기다리는 동안 갈매봇이 지금 무엇을 하는지 한 줄씩 보여 준다.
  • 4카드 수정. 「수정」을 누르면 값이 그 자리에서 편집된다. 다시 말로 설명하지 않아도 된다.
  • 5세 가지 크기. 떠 있는 위젯 → 옆에 붙인 패널 → AI 올인원 탭. 머리말 오른쪽 버튼으로 바꾼다.
  • 6확인 대기 탭. 버튼의 숫자와 같다. 다른 화면에서 만들어 둔 오더를 여기서 마저 처리한다.
02

위젯 상태

구현할 때 빠뜨리기 쉬운 상태를 따로 펼쳤다. 데모에서 재현하기 어려운 장애·만료·권한 없음이 여기 있다.

A생각 중
새움에듀 데모 끝났어. 상태 바꾸고 내가 맡을게.
새움에듀 찾음 · 부산 해운대
현재 상태 확인 · 상담 중
오더 작성 중

단계가 끝날 때마다 줄이 추가된다. 기다리는 동안 입력은 잠기고 「중지」만 누를 수 있다.

B카드 수정 중

대상(고객)은 수정 모드에서 바꾸지 못한다. 대상을 바꾸려면 새 오더를 낸다 — 엉뚱한 고객에 실행되는 것을 막는다.

C만료

그 사이 데이터가 바뀌었을 수 있어 같은 카드를 되살리지 않고 새로 작성합니다.

오래된 카드의 확인 버튼이 남아 있으면 바뀐 데이터 위에 실행될 수 있다. 만료되면 버튼을 없앤다.

D실행 실패

실패를 성공처럼 보이게 하지 않는다. 무엇이 나갔고 무엇이 안 나갔는지를 먼저 말한다.

E갈매봇 장애
이번 주 매출 요약해 줘.

지금은 답변을 만들 수 없습니다. 화면으로 바로 이동할 수 있습니다.

AI가 멈춰도 위젯은 화면 이동 도구로 남는다. 확인 대기 오더의 실행·취소는 AI 없이도 동작한다.

F조회 권한 없음
이번 달 매출 얼마야?

갈매봇은 그 사람이 화면에서 볼 수 있는 것만 답한다. 권한 밖의 숫자를 요약으로 흘리지 않는다.

03

오더 카드 — 구조 · 상태 · 등급

카드 한 장의 구조, 상태에 따른 변화, 등급별 차이 순서로 본다. 모든 카드는 눌러 볼 수 있다 — 수정, 실행, 되돌리기, 발송 유예까지.

  1. 1무엇을 · 누구에게. 오더 이름 아래에 대상을 굵게 둔다. 대상이 첫 줄에 있어야 엉뚱한 고객에 실행하는 실수가 준다.
  2. 2등급. 글자(R2 변경)와 머리 옆 짧은 막대 색으로 두 번 알린다. 색만으로 구분하지 않는다.
  3. 3값. 바뀌는 값은 「이전 → 이후」 한 줄. 이전 값은 흐리게, 이후 값은 굵게. 취소선은 한글에서 읽기 어려워 쓰지 않는다.
  4. 4건드리지 않는 것. 이 오더가 바꾸지 않는 항목을 적는다. 「상태만 바꿨는데 메모가 날아갔다」는 걱정을 미리 없앤다.
  5. 5상태와 남은 시간. 확인하지 않으면 15분 뒤 만료된다. 남은 시간이 흐르는 것이 보인다.
  6. 6행동. 실행이 맨 앞, 취소가 맨 뒤. 확인 버튼에 자동 포커스를 주지 않는다.
  7. 7안내. 되돌릴 수 있는지와 필요한 권한. 되돌릴 수 없는 오더는 여기가 경고색이 된다.
한 카드의 상태 변화같은 오더가 상태에 따라 어떻게 보이는지. 버튼은 모두 동작한다

배치 규칙 — 다른 요소와 겹칠 때

우하단은 이미 여러 화면이 쓰고 있다(하드웨어 재고의 빠른 기록 버튼, 매출 장부의 떠 있는 버튼, 저장 알림, 오른쪽 서랍). 갈매봇 버튼이 그 위를 덮지 않도록 자리를 정한다.

기본

우하단. 화면에 떠 있는 요소가 없을 때.

+ 빠른 기록
화면에 자체 버튼이 있을 때

화면의 버튼이 자리를 지키고 갈매봇이 그 위로 올라간다. 화면의 주 작업이 우선이다.

오른쪽 서랍이 열렸을 때

서랍 왼쪽으로 비켜난다. 서랍의 저장·닫기 버튼을 가리지 않는다.

저장했습니다
알림이 뜰 때

모바일

옆에 붙였을 때

컨택 기록 1건을 남길까요?

다음 주 재연락 할 일도 필요하면 말씀해 주세요.

  • 1하단 시트 80% 높이. 뒤 화면이 살짝 보여 어디서 열었는지 잊지 않는다. 손잡이를 내리면 닫힌다.
  • 2버튼은 가로 전체 폭. 확인 버튼을 엄지로 누를 수 있는 자리에 둔다.
  • 3이어지는 작업은 알려만 준다. 갈매봇이 다음 오더를 알아서 만들지 않는다. 사람이 말해야 카드가 나온다.
  • 4키보드가 올라오면 시트가 화면 전체 높이로 늘어나고 입력창이 키보드 바로 위에 붙는다.
  • 5음성 입력은 뒤 단계. 글자 입력으로 먼저 검증하고, 음성은 별도 기획으로 붙인다.
