# 매출 장부 컴팩트 매트릭스 — 시안 A-2 구현

기준 시점: 2026-11-20
대상 화면: `/admin/branch/ledger` 기본 「장부」 보기(월 요약)
시안: [캔버스 · 매출장부 시안](https://claude.ai/artifact/BszqC4dqke8hPb7kBXjGqQ)(비공개 artifact) — A 시트형 · B 기간 레일 · C 프리셋 뷰 → A 선택 → 색 시안 A-1 구조 강조 · A-2 확도 강조 → **A-2(2차) 확정**

구현 사실은 코드가 우선한다. 이 문서는 무엇을 왜 바꿨는지와 남은 결정을 적는다.

## 1. 요구(사용자)

1. 더 컴팩트하게, 화면을 넓게 쓴다. 고객 옆 라벨은 한 줄로, 복잡하면 호버로.
2. 기본 화면은 로그인한 매니저의 담당분.
3. 필터·정렬 — 월별·주별로 숫자 있는 행을 빠르게 거른다.
4. (A 선택 뒤) 글자색·배경색으로 더 잘 보이게.
5. (A-2 선택 뒤) 월 열을 구분하고 지난달은 다른 배경 + 고정. 고객·제품(HW/SW)은 좌우 스크롤 때 고정, 지역·계약(신규/갱신) 등은 고정하지 않는 별도 열.

기존 화면의 문제: 경로 → 28px 제목 → 설명문, 범위 줄, 상태 줄, 탭, 큰 요약 타일 5개가 표 위에 쌓여 표가 첫 화면 아래로 밀렸다. 표는 지난달을 한 열로 묶고 주차를 보여 주지 않아, "이번 달·이번 주에 숫자 있는 고객"을 고르려면 주차 검수 보기로 넘어가야 했다.

## 2. 바뀐 화면 규칙

| 항목 | 규칙 |
|---|---|
| 열 | 고객 · 제품 · 지역 · 계약 · 경로 · (담당 — 내 담당 범위가 아닐 때) · FY 합계 · 12개월. 달마다 따로 보이고(지난달 묶음 열 없음) 주차(w1–w5)로 펼칠 수 있다. 처음엔 이번 달만 펼침 |
| 좌우 고정 | 고객 · 제품. `지난달 고정`(기본 켬)이면 최근 지난달 4개도 그 옆에 고정. 지역 · 계약 · 경로 · 담당 · FY 합계는 고정하지 않는다. md 미만 폭에서는 좌우 고정을 끈다 |
| 거르기 | 열 머리의 깔때기 = 그 달/주에 숫자 있는 행만(여러 개면 AND). 빠른 버튼 `이번 주 · 이번 달 · 다음 달 값 있음`은 같은 상태를 켠다. 걸린 필터는 칩으로 보이고 `초기화`로 한 번에 푼다 |
| 정렬 | 열 머리 이름. 숫자 열은 내림 → 오름 → 해제, 글자 열은 오름 → 내림 → 해제. 해제하면 FY 합계 큰 순 |
| 합계 | 머리줄 바로 아래 고정 행(보이는 줄의 열별 합). 표 아래 확정·고확도·예정 3행과 월 목표 대비 행은 유지 |
| 면 | 지난달 = 회색 면 한 가지(숫자는 확도 글자색). 이번 달부터 숫자 있는 칸 = 확도 틴트(섞임은 뉴트럴). 다음 달들은 한 달 건너 옅은 띠. 이번 달·이번 주 머리 = 그린. 주차↔월 불일치 칸 = Danger 틴트. 값 정본은 `DESIGN.md` §2 「장부 매트릭스 칸 틴트」 |
| 라벨 | 채움 pill 없이 글자색만. 드문 값(HW · 신규 · 채널)만 진하게. 한 고객에 딜이 여럿이라 값이 갈리면 `SW·HW`처럼 잇고, 칸을 넘치면 말줄임 + `title` |
| 금액 | 칸에는 축약(1.0만) 없이 전체 자릿수, 0은 빈칸, ¥는 조작줄에 `단위 ¥` 한 번. 칸 폭을 넘는 큰 합계만 만·억으로 줄인다(`title`에 원값) |
| 편집 | 월 칸을 그 자리에서 고치는 기존 흐름(`LedgerCellEditApi` → 초안 → 확인 → 반영) 그대로. 주 칸은 읽기 전용(주차 수정은 주차 검수 보기) |
| 머리 | 제목 20px + 경로 + 통화 안내를 한 줄로. 범위 버튼(내 담당 · 전체 담당자)은 데스크톱 32px, 눌린 쪽을 그린 선·글자로 표시. 장부 요약은 타일 5개 → 한 줄 |

### 주차 칸의 확도

파이프라인 행에는 주차별 확도가 따로 집계돼 있지 않다. 월 집계(캐논 `rowMonthBucket`)와 모순되지 않게 다음 순서로 정한다.

1. 그 달이 한 확도뿐이면 주차도 그 확도.
2. 섞여 있고 초안 행에 주차별 확도 기록(`weeklyConfidence`)이 있으면 그 값.
3. 섞여 있고 시트의 주차 칸 글자색(`weeklyColors` — r/b/k)이 있으면 확정/고확도/예정.
4. 그 밖에는 월 비율대로 나눠 "섞임"으로 보인다.

### 지난달 고정의 상한

회계연도가 4월 시작이라 11월이면 지난달이 7개, 2월이면 10개다. 전부 고정하면 고정 폭이 화면을 다 차지하므로 **이번 달 바로 앞 4개 달만** 고정한다(`MATRIX_PINNED_PAST_MONTHS`). 더 오래된 달은 회색 면은 그대로이고 평범하게 스크롤된다.
