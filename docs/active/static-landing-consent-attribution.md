# 정적 랜딩의 동의와 광고 귀속

정적 랜딩의 광고 식별자와 UTM, 전체 URL 및 referrer는 동의 상태를 안전하게 확인할 수 있는 방식이 마련될 때까지 저장하거나 신청 데이터에 첨부하지 않습니다. 따라서 이 랜딩에서 직접 신청하거나 다른 페이지로 이동한 신청의 캠페인 귀속이 누락될 수 있습니다. 문의 및 행사 신청은 그대로 가능합니다.

복원하려면 현재 정책 버전과 철회 마커를 확인하고, 탭 간 변경과 지연된 응답을 안전하게 처리하는 동의 확인 및 저장 설계를 적용해야 합니다. 관찰 기능이 없는 브라우저는 선택적 수집을 거부 상태로 유지합니다.
