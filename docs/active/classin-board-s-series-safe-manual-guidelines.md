# ClassIn Board S 시리즈 안전 사용 기본 지침

## 1. 출처와 적용 범위

- 출처: `ClassIn Board S系列说明书`, 24쪽, S65·S75·S86·S110(2.0) 계열 사용설명서.
- 이 문서는 고객 안내용 한국어 기준이다. 원문 PDF의 세부 UI 명칭은 모델·펌웨어에 따라 달라질 수 있으므로, 실제 기기 화면과 설치 담당자의 인수인계 내용을 우선한다.
- 공개 문서에서는 불안을 키우는 경고문보다, 사용자가 바로 행동할 수 있는 권장 순서와 점검 문장으로 바꿔 쓴다.

## 2. 안전 안내의 기본 톤

- 전원·설치·분해·이상 증상처럼 사고 위험이 있는 항목은 명확하게 쓴다.
- 일반 운영 팁은 "권장합니다", "확인합니다"처럼 부드럽게 안내한다.
- 고장 원인을 단정하지 않고, 사용자가 먼저 확인할 수 있는 범위를 안내한 뒤 설치 담당자나 A/S로 연결한다.
- 어린 학생이 쓰는 교실 환경을 전제로, 케이블·스탠드·벽걸이·액체·날카로운 물건·장시간 고정 화면을 특히 조심하도록 쓴다.

## 3. 전원·환경 안전

- 제품 라벨에 표시된 전원 규격을 사용하고, 접지된 3구 전원 콘센트를 권장한다.
- 멀티탭을 쓸 때는 정격 용량을 확인하고, 통로에 전원선을 지나가게 두지 않는다.
- 낙뢰가 있거나 장기간 사용하지 않을 때는 전원 플러그와 네트워크 케이블을 분리하는 안내를 기본값으로 삼는다.
- 이상한 소리, 냄새, 연기, 액체 유입이 있으면 즉시 전원을 끄고 플러그를 뽑은 뒤 사용을 중지한다.
- 제품을 직접 분해하거나 커버를 열도록 안내하지 않는다. 점검·수리는 전문 담당자 또는 A/S 경로로 연결한다.
- 저온 환경에서 따뜻한 공간으로 옮긴 직후에는 내부 결로가 생길 수 있으므로, 충분히 건조한 뒤 전원을 켜도록 안내한다.

## 4. 설치·이동·배치

- 대형 보드는 무게와 유리 패널 때문에 여러 명이 함께 이동해야 한다. 원문 기준 이동은 6명 이상 협업을 전제로 한다.
- 바닥형 설치는 받침대를 단단히 고정하고 평평하고 안정적인 바닥에 둔다.
- 벽걸이 설치는 제품과 벽걸이 브래킷 기준에 맞춰 단단히 고정해야 하며, 벽면 재질과 보강 필요 여부를 설치 전 확인한다.
- 직사광선, 습기, 과열·과냉, 먼지가 많은 곳, 통풍이 나쁜 곳, 가연성·부식성 가스가 있는 곳은 피한다.
- 통풍구를 신문, 천, 커튼, 수납물로 막지 않는다.
- 이동형 스탠드를 쓸 때는 급정지, 급회전, 경사 바닥을 피하고 이동 동선을 미리 비운다.

## 5. 화면·터치·청소 관리

- LCD 패널의 주요 재료는 유리이므로 화면을 누르거나 충격을 주지 않도록 안내한다.
- 날카로운 물건이나 금속 물체를 통풍구, 단자, 화면 주변에 넣거나 접촉시키지 않는다.
- 같은 화면, 고정 아이콘, 정지된 텍스트를 장시간 표시하면 잔상이 남을 수 있으므로 화면 보호와 절전 운용을 권장한다.
- 청소 전에는 전원을 끄고 플러그를 분리한다.
- 화면은 물을 아주 조금 묻힌 부드러운 반건조 천으로 가볍게 닦는다.
- 알코올, 휘발유, 산·알칼리 세제, 시너, 휘발성 용제는 코팅과 외관 손상 가능성이 있어 피하도록 안내한다.
- 습도가 높은 날 화면 안쪽에 일시적인 김서림이 보일 수 있으며, 정상 사용 환경에서 시간이 지나며 사라질 수 있다. 다만 물방울, 누수, 이상 동작이 있으면 사용을 중지하고 점검을 요청한다.

## 6. 기본 조작 기준

- 전원 버튼은 AC 전원 연결 후 시스템 시작, 실행 중 설정 화면 호출, 길게 눌러 종료 흐름에 사용한다.
- 대형 화면 제어 메뉴에서는 투영, 주석, 터치 잠금, 눈 보호, 입력 소스, 설정, 볼륨, 밝기, 화면 끄기, 재시작, 종료를 다룬다.
- 수업 중 학생이 화면을 만지거나 청소해야 할 때는 터치 잠금을 먼저 안내한다.
- 눈 보호 모드, 밝기, 볼륨은 교실 조도와 학생 좌석 거리에 맞춰 조정하도록 안내한다.
- 전원을 켰을 때 기본 입력은 내장 OPS 채널을 기준으로 보되, 현장 설정이나 펌웨어에 따라 다를 수 있다고 둔다.
- 입력 소스가 회색으로 보이거나 선택되지 않으면 해당 포트에 신호가 없는 상태로 보고 케이블, 외부 기기 전원, 입력 포트를 확인한다.

## 7. 포트·네트워크 사용 기준

- Android USB 2.0 포트는 Android 시스템 업그레이드 용도 중심으로 안내하고, 일반 USB 장치는 공용 USB 포트를 우선 사용하도록 안내한다.
- 무선 키보드·마우스가 끊기면 USB 수신기를 다른 포트로 옮기거나 USB 연장선을 써서 수신 범위를 확보한다.
- HDMI로 외부 기기를 연결할 때 터치 입력까지 필요하면 HDMI 신호와 터치 입력 연결을 함께 확인한다.
- Type-C는 충전, DP 신호 표시, USB 연결을 지원할 수 있으나, 케이블은 짧고 규격이 확실한 제품을 권장한다. 원문 기준 1.5m 이내 사용을 기본 안내로 둔다.
- LAN 포트는 유선 네트워크와 네트워크 공유에 쓰일 수 있다. IP 설정은 자동을 기본으로 두고, 수동 IP는 담당자가 주소·서브넷·게이트웨이·DNS를 확인한 뒤 설정한다.

## 8. 수업 중 권장 운용

- 무선 투영은 보드와 기기가 같은 네트워크 또는 보드가 안내하는 무선 핫스팟에 연결된 상태에서 진행한다.
- 주석 기능은 수업 중 강조 표시, 회의 중 체크, 화면 위 필기 용도로 안내한다.
- 부분 지우기는 지우개 도구나 넓은 면 터치로, 전체 지우기는 삭제 기능으로 안내한다.
- 주석 도구 모음은 흰색 도구 막대를 잡고 옮길 수 있으며, 종료 버튼으로 빠져나온다.
- 5손가락 제스처로 여는 작은 제어 화면은 큰 화면 조작이 불편하거나 비밀번호·개인 파일처럼 민감한 내용을 다룰 때 쓰는 보조 조작 패널로 안내한다.

## 9. 공개 문서·챗봇 답변에 쓰는 요약

ClassIn Board S 시리즈를 안내할 때는 전원·접지·환기·설치 안정성·화면 보호를 먼저 확인하고, 사용 중 이상한 소리나 냄새, 액체 유입, 터치 이상이 있으면 즉시 전원을 끄고 A/S로 연결합니다. 기본 조작은 대형 화면 제어 메뉴에서 투영, 주석, 터치 잠금, 눈 보호, 입력 소스, 설정, 볼륨과 밝기를 조정하는 흐름으로 안내하고, 포트·네트워크·수동 IP 설정은 현장 담당자가 실제 연결 상태를 확인한 뒤 진행하도록 권장합니다.
