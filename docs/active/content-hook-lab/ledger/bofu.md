## 장점 풀 (최대 30)

- 윗선·강사의 실제 반론을 인용 대사로 후킹에 쓴다("대표님이 '…' 물으시면") — L5-13·L5-01
- (앵글) 지난번 견적·설치 실패 고백 + 받아 둔 견적서를 가져오라는 행동("지난번 견적서엔 카메라가 없었어요", 4회 74.4~82.1) — 2026-11-03 B-L2-10
- 반론을 질문 그대로 후킹으로 쓴다("칠판은 있는데 왜 또 바꾸나요?") — L3-20
- 범위를 교실 하나·한 반으로 좁혀 안심시킨다 — L5-11·L3-10·L1-02
- 행동 단위를 가장 작게 만든다(수업 한 편, 교실 사진 한 장) — L5-07·L3-02
- 시간·범위를 못 박는다("쇼룸 30분, 3장면") — L4-17
- 고객 자기 자산을 올려 보게 한다(우리 교재 한 단원, 쓰던 수업 한 편) — L3-15
- "확인한 뒤 답합니다"류 정직 선언을 후킹으로 쓴다 — L1-06·L2-10
- 한계를 먼저 인정해 안심시킨다("결제는 지금 쓰는 시스템 그대로") — L5-15
- 책임 주체를 묻는 질문("누가 챙기나요?", "교안, 어디 있나요?") — L3-08·L4-15
- 순서를 뒤집는다(수업을 올려 보고 견적 받기) — L3-06
- (앵글) 세 페르소나 모두의 비용 걱정을 속마음 인용으로 묻는다("파일럿 끝나고 안 하면 위약금 있나요?", 패널 82.2) — 2026-11-02 디벨롭 B-L3-14(84.5, 재채점 71.7·75.3)
- (구조) 반대하는 사람의 자료를 가져오게 한다("반대하는 쌤 교안으로 해 봐도 돼요?" 76.2·78.3) — 2026-11-03 B-L2-11
- 확인 못 하는 것을 먼저 말하는 정직 선언("카메라 못 다는 교실도 있습니다", "모든 교실에 되는 건 아닙니다") — 2026-10-30 B-L1-07·B-L4-03
- 장면 + 책임 주체 질문("문제가 생긴 아침, 누구에게 연락하죠") — B-L5-08
- 말하기 어려운 계약·해지 질문을 먼저 꺼낸다("중간에 그만두면 어떻게 되나요?") — B-L1-13
- 전환 비용 불안을 직격하고 구체 다음 행동으로 잇는다("교안 다시 만들어야 하나요?" → 한 단원 가져와 쇼룸) — B-L5-15
- 질문을 인용하고 가능 여부는 사진으로 확인한다("우리 교실은 다 되죠?") — B-L4-12
- 되는 교실/어려운 교실을 구분하는 선언 — B-L5-05
- 쇼룸 첫 확인 장면 하나·강사 동반 30분처럼 작고 명확한 다음 행동 — B-L5-18·B-L1-06
- 방문·견적을 앞둔 속마음을 따옴표로 인용하고 곧바로 부담을 낮춘다("쇼룸 가면 사야 할 것 같아서요") — 2026-10-31 B-L5-02(5루프 내내 상위)
- 확인할 수 없는 것을 먼저 말하는 정직 선언("쇼룸에서 못 보여 드리는 것부터 말씀드립니다", "3개월이면 다 되나요?") — B-L5-04·B-L1-20
- 낮은 문턱의 구체 행동("설치 전에 교실 사진 한 장 보내도 되나요") — B-L5-18
- 견적서 속 구체 칸을 짚는 질문 인용("이 견적서, 뭐가 빠진 건가요?") — B-L3-07
- 계약·견적 앞의 걱정을 22질문 키트로 잇는다("견적 받으면 계약부터 하자고 할 것 같아요") — B-L5-14
- (구조) 이미 받은 견적서를 가져오라는 구체 행동 질문("두 견적서, 설치 범위부터 같이 봐 주나요") — 2026-11-01 B-L2-15(81.2)
- (구조) 중단·해지 같은 말하기 어려운 질문을 정면으로 묻는다("써 보다 그만두면 어떻게 되나요", "90일 파일럿, 중간에 멈춰도 되나요") — B-L1-10(83.0)·B-L5-15
- (구조) 도입 반론을 인용으로 꺼내고 나눠 보자고 잇는다("사면 할 일만 늘 것 같아서요") — B-L5-10
- (앵글) 전에 산 장비의 실패를 고백하는 인용("전에 산 칠판도 결국 TV가 됐어요", 3루프 82.1·79.0·75.7) — 2026-11-02 세그먼트 B-L3-10
- (앵글) 가장 반대하는 사람을 동행시키는 질문을 인용한다("제일 반대하는 쌤을 데려가도 되나요?") — 2026-11-02 세그먼트 B-L3-07(85.4, 재채점 74.3·77.7)

## 피할 패턴 (최대 20)

- 안내문·명령형·공지투 후킹("…확인하세요", "…표시해요", "…회신합니다")
- 설명 문장형·불완전 문장 후킹
- 카피에 근거 없는 정량 단정("반으로 줄어듭니다") — 하드 게이트 2
- 줌 경험자 한정 소재의 반복(대상이 좁아 점수 하락). 세그먼트 패널에서도 개인 강사의 상담 가능 여부만 묻는 후킹("개인 강사가 물어봐도 될까요?" 45.1, "개인 강사도 상담받을 수 있나요?" 36.5)은 최하위
- 앞 루프 Top3의 복제본("대표님께 보여 드릴 수업 한 편" 계열 변주)
- MOFU 성격 소재(비교표·SOP·도구 비교·3분 판단)와 운영 세부 질문("지점 교안 변경 알림도 상담 범위인가요" 30.2, "복습 링크 인수인계도 온보딩에 들어가나요" 35.6)을 BOFU 후킹에 그대로 쓰기
- 이미 도입한 사용자용 운영 팁(보강 안내 자동화 등)
- 숫자 나열만 있는 후킹, API 등 개발자 용어
- 녹화·정책 질문 변주 반복(같은 리스크를 여러 번 쓰면 변별력 하락)
- 답을 "확인해 보세요/상담에서 확인"으로만 미루는 질문 후킹·카피와 부정형으로 시작하는 후킹(보상이 약해 김빠짐) — 2026-11-03에도 "지금 쓰는 줌, 같이 써도 되나요?"(36.5), "지금 프로그램이랑 학생 명단이 이어지나요?"(41.0)가 최하위
- 리스트형·숫자 나열 안내문("N가지", "N개 조건")
- 공급자 중심 "알려드립니다" 안내문 투 후킹
- 같은 정직 선언 계열(설치 한계)을 한 루프 Top3에 여러 개 배치: 같은 앵글은 1개만
- 항목명 나열형 후킹, TOFU·MOFU 성격(학부모 설명, 다시보기 화면)을 BOFU에 그대로 쓰기
- 단정에 가까운 효과 문구("설득이 쉬워집니다")
- 쇼룸 방문 불안 계열(구매 압박·못 나올 것 같다·계약서)을 한 루프에 4~5개 두는 것, 같은 카피에 후킹만 바꾼 변이(거절 못 할까 봐요, 분위기상 사게 될까 봐요, 쇼룸 가는 것도 부담): 서로 중복 판정을 받는다
- MOFU 로드맵·계획서 문구형, 항목명 나열·설명서형 후킹
- 교사 온보딩 소재(도입 후 단계)를 BOFU 결정 장면에 그대로 쓰기
- 같은 카피에 후킹만 바꾼 변이를 한 루프에 여러 개 두는 것(쇼룸 부담 인용, 두 견적서): 중복 판정으로 원본보다 크게 낮다(81.2 → 59.1)
- BOFU에서 미완성 어미("~했더니", "~하면")나 결과를 단정하는 후킹("견적서 사진 한 장이면 설치 범위를 봅니다"): 33~46점대
