## 1. 요약

- **방향은 그대로, 해상도를 올린다.** Classin의 고급스러움은 꾸밈이 아니라 잘 편집된 교육 전문지의 차분한 자신감과 증거에서 나온다. 승인된 목표를 그대로 지으면 18섹션, 가운데 정렬 머리, 700 굵은 제목과 제목 속 그린 구절, r8·r12 상자, 17번 바뀌는 지면, 출처 없는 도판이 새 토큰으로 다시 만들어진다. 고급화는 여기서 한 번 더 빼고 더 정밀하게 하는 일이다.
- **일곱 기둥**
  1. 짧은 목차, 한 지면에 한 주장 — 홈 18섹션 → 11지면(V10).
  2. 왼쪽 레일 위의 조판 — 12칸 그리드, 레일에 폴리오·라벨, 큰 제목은 가볍게(V13), 모바일 자간은 0 대신 줄인 음수.
  3. 그린과 둥근 모서리는 누를 수 있는 것에만(V12·V14).
  4. 한 장의 종이, 적은 상자, 가는 선 — 지면·띠·사진 흰점을 같은 온도로(V15), 글 카드는 열린 단, 흰 sheet는 물건에만.
  5. 같은 빛의 증거 도판 — 출처 장부, 현장·사물·화면 3계열, 매트(V16)와 콘텐츠 폭 plate.
  6. 정지한 지면, 잉크 한 획 — Hero는 인쇄된 상태, 잉크 밑줄 하나만 움직임(V17).
  7. 조판된 사실로 얻는 신뢰 — 숫자는 레지스트리 + 각주, 후기는 사례 3 + 인용 4, 가격 대신 견적 구성표.
- **디자인과 별개로 먼저 고칠 것이 있다.** 사실 확인에서 출처 없는 수치·과장 문구·개인정보 노출이 운영 화면에 남아 있는 것을 확인했다(§7). P2 전에 핫픽스(H)로 고치기를 권한다.

## 4. 결정 없이 채택하는 것

심사 셋이 모두 채택했고 취향 문제가 아닌 것. 괄호는 제안 ID와 단계.

**조판**
- 12칸 그리드 + 왼쪽 레일(64rem 이상: 레일 1–3, 본문 4–12, 여백 10–12). 공개 h1/h2 가운데 정렬 금지(StateBlock·Dialog 제외). ChapterHead = masthead → 레일 Kicker + 본문 H2 → 덱 (TY-1, P2 → P3–P5)
- 페이지 제목 `text-h1` 36→56px, 시뮬레이터(`/pricing/simulator`·`/krw`) 결과 금액은 `text-h2`로(`/pricing` 카드에는 금액 없음) (TY-6, P2)
- 모바일 자간: (width < 40rem)의 0 재정의를 줄인 음수 표로. 먼저 `globals.css` h1–h4 모바일 `letter-spacing:0 !important`를 어드민 전용으로 옮긴다(이것이 P2 첫 커밋) (RA-1·TY-2, P2)
- 단독 숫자는 비례, 표·가격·폴리오·날짜는 tabular. 인용 여는 따옴표 `text-indent:-0.45em`. 한글 사이 가운뎃점 공백 0('전·중·후'). 14px 이하 600은 라벨·폼 라벨·버튼·'예시' 태그만 (TY-7·RA-6, P2)

**그린 배급** (CO-4·RA-2·CO-3, P2)
- 제목 속 그린 0. `heading-accent` 가드를 새로 만들어 warn 래칫으로 시작한다(지금 가드에 없음).
- 비상호작용 그린 표지(잉크 밑줄·● 묶음·좌측 2px 바·차트 강조·인용 따옴표)는 뷰포트당 2개 이하, 그린 채움은 primary 1개. 카드 범주·지역 라벨은 muted.
- hover는 밝아지지 않고 짙어진다: `#073D2D`(지금 `#065C41`은 운영자가 거부한 밝은 그린 `#0c5d44`와 거의 같다). 먹 위 accent·hover는 세이지 `#8FC4AC`(먹 #1A1917 위 8.92:1), 먹 위 링크 밑줄 `rgb(143 196 172/.6)`.
- selection: 밝은 지면 `rgb(8 71 52/.14)` + 글자 #111110(13.9:1). 먹 위는 세이지 알파 + **글자 #FAFAF8**(지금 `site-base.css`는 글자를 #111110으로 고정하므로 `.surface-ink ::selection` 재정의가 필요).
- 'OKLCH L ≤ .36' 규칙은 글자·채움 상태값에만 적용한다(selection·밑줄 합성색은 제외).

**상자 줄이기**
- 글만 있는 카드(인덱스·후기·가치)는 열린 단: 위 hair + 32/48 간격 + 64rem 이상 단 사이 세로 hair. 링크 단은 화살표를 늘 보이고 히트 영역은 단 전체. `card.tsx`에 공개 family `column` 추가, legacy는 바이트 그대로 (CO-9)
- 흰 sheet는 섹션 지면에서 빼고 물건(Frame·plate·요금·사진 있는 사례·폼·표)에만. sunken은 도해·부록·FinalCTA 3역할, 먹은 Manifesto + 푸터 (RA-7)
- 헤어라인: 기본 1px, 2dppx 이상 .5px + α .14, 먹 위 .5px + .20, `prefers-contrast: more` 1px + .32. 실기기 확인 (CO-5)

**도판** (IM-1~9·CO-7·CO-8·RA-5·TY-8)
- 출처 장부 `data/image-credits.json`(file·family·kind·credit·origin·consentDocId·verifiedAt·frozenBy). Figure/Frame은 id만 받고, 새 도판은 `verifiedAt` 없으면 빌드 실패, 기존 도판은 라우트 PR마다 래칫.
- 3계열(현장·사물·화면) 빛 레시피, 공개 도판 평균 휘도 100/255 이상(HW 먹 장 1장 예외). 보드 화면 속 우주·자연 배경, 시네마틱 다크 키, 네온 유리 컷 금지. 대체 전 빈 Frame 0.
- 화면 도판 2종: 전체 캡처(1920×1200, 페이지당 1)와 영역 캡처(720×450 CSS px, DPR2). 라이트 테마·한국어 시드·창틀/커서/알림/딤 0, 개인정보는 `--surface-skeleton` 단색 블록(블러 금지).
