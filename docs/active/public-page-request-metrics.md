# 공개 페이지 요청 지표

Analytics 방문자 탭의 **전체 페이지 요청**은 Vercel Observability의 운영 도메인 요청을
한국 시간 일 단위로 합산한다. 분석 쿠키 동의 여부에 따라 거르지 않는다. 인증된 관리자만
`/api/admin/public-page-requests`에서 합계와 일별 숫자를 읽는다.

- GET HTML 응답을 센다. 관리자·API·계정·공유 링크 등은 제외하고, 확인된 봇과 프리페치도 제외한다.
- 이 값은 방문자나 세션 수가 아니다. 반복 요청, 미확인 봇은 남고, 캐시 응답과 사이트 내부
  클라이언트 이동은 빠질 수 있다. 동의 기반 `client_events` 방문자와 합하거나 서로 빼지 않는다.
- 최근 7·14·30일을 지원한다. Vercel 보존 한도 때문에 90일은 부분 합계로 표시하지 않는다.
  긴 기간은 7일 단위로 나눠 조회하며 각 응답과 합계를 검증한다. 한 구간이라도 실패하면
  전체를 미상으로 표시하고 오류를 0으로 캐시하지 않는다.
- 서버 환경에 `VERCEL_TRAFFIC_TOKEN`이 있어야 한다. 운영 팀·프로젝트의 Observability를
  읽을 수 있는 전용 최소 권한 토큰을 사용하고 클라이언트 변수로 노출하지 않는다. 토큰 미설정,
  권한 오류, 시간 초과 또는 외부 장애는 "확인 필요"다.
- 외부 집계는 다른 트래픽 통계와 별도 요청이다. 2분 캐시와 같은 프로세스 내 중복 요청 합치기를
  적용한다. 30일 첫 조회는 느릴 수 있다.
