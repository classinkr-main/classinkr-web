## 3. 약점 (충실도) — 오류 패턴
세부 UI 텍스트에서 **OCR성 오독 + 환각**이 약점. 패턴:
1. **부정·범위 의미 역전 (가장 위험)** — 예: "편집 불가능"을 "편집 가능"으로, 적용범위 "모든 코스"를 "활성화 시점 코스만"으로.
2. **작은 한글 UI 글자 오독** — 웹→챕, 기관→가공, 결제→경제, 교실→고실, 지연 및 튕김→자연 발리, 답변→답글, 수업(66개)→(56개).
3. **그럴듯한 내용 환각** — 존재하지 않는 경고문·상태 라벨('문제 인식 성공')·제품화면('AI Agents')·디바이스명(TR-Camera) 발명.
4. **단계 과분할** — 이미지 3·6단계를 6·9단계로 부풀림.
5. **주석 상태 오류** — 없는 빨간 박스/화살표/버튼 색을 있다고 기술.
6. **추적성** — 전사 `name` 4건이 리타이틀돼 원본 파일 매핑이 깨짐(검증 셋업에서 수정).
