# 홈페이지 관리자 요청 점검

## 요청을 찾고 공유하기

관리자 계정으로 `/admin/requests`를 열면 요청 관리 목록이 먼저 표시된다. 미확인·재확인 요청을 고르거나 제목, 분류, 상태로 검색한다. 목록에서 화면 경로와 테스트 버전을 확인할 수 있다.

요청 상세에서 ‘요청 링크 복사’를 누르면 `/admin/requests?request=<요청 ID>`가 생성된다. 해당 요청을 볼 권한이 있는 관리자나 요청자가 로그인하면 바로 상세로 이동한다.

## AI에 전달하기

관리자는 요청 상세에서 ‘AI 점검 자료’를 펼쳐 공유할 내용을 확인하거나 편집한 뒤 복사한다. Markdown에는 제목, 내용, 상태, 화면 경로, 테스트 버전과 연결 가능한 샘플 주소가 들어간다. 원본 로그, 캡처와 답변 기록은 요청 상세에서 확인한다.

인증된 관리자 세션에서 `GET /api/admin/requests?view=manage&queue=unacknowledged`로 미확인 목록을 조회하고, `GET /api/admin/requests?view=manage&id=<요청 ID>&format=markdown`으로 개별 점검 자료를 읽을 수 있다. 개별 응답은 UTF-8 Markdown 텍스트다. 제목과 내용에는 기존 개인정보 가림과 토큰 가림을 적용하며 이름, 주소와 비정형 비밀값은 공유 전에 확인한다.
