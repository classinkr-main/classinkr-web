## 1. 요약

- 가이드 탭에는 **설치·로그인을 찾는 사용자와 도입을 검토하는 사람이 한 서랍에** 들어 있다. 분류 축도 셋(역할·제품·시점)이 섞여 같은 일이 두 곳에 있고, 문제 해결 9편은 네 분류에 흩어져 모아 보는 화면이 없다.
- 화면은 공개 디자인 언어(편집 지면 · V1–V26)로 아직 옮겨지지 않았다. 제목 900, 그린 대문자 라벨, 밑줄 검색처럼 지금 규칙과 어긋난 곳이 9군데다(§3).
- 시안 4가지는 **무엇을 축으로 세우느냐**로 갈린다: A 지금 구조 정리 · B 증상 먼저 · C 역할 × 수업 흐름 지도 · D 문서 셸. 추천은 **E = B의 표지 + D의 셸 + C의 흐름 묶음**이다.
- 어느 시안이든 먼저 할 공통 바닥 6개(F1–F6)가 있다. 이 문서와 함께 F1의 일부(홈 검색 0건일 때 비슷한 검색어)를 반영했다.

### 추천 E — 디벨롭판

- **홈(위에서부터)**: 검색(질문도 받음) + 많이 찾는 검색어 → **01 처음이라면**: 기능 소개서 · 기본 튜토리얼(설치 → 가입 → 코스 참여 3단계, 학원은 첫 7일) · 유튜브 가이드 재생목록 → **02 안 될 때**: 증상 8칸(각 칸에 '이것부터' 한 줄) + 문제 해결 전체 → **03 역할별 사용법**: 시작하기 · 수업 준비 · 수업하기 · 수업 끝나고 · 학원 운영 · 전자칠판·장비 6묶음, 역할 칩으로 거르기 → 업데이트 한 줄 → **04 도입 검토**(sunken 띠, 6편 주소 유지) → 도움 한 줄.
- **문제 해결 허브 `/docs/fix`**(신설): '일단 이것부터' 4가지 · 사용 기기 칩 · 접속·계정 / 수업 중 / 수업 후 3묶음 9편 · 해결이 안 되면(보낼 정보 3가지).
- **문서**: 1440 셸(트리 256 · 본문 720 · 목차 208). 트리는 '처음이라면 · 안 될 때'를 맨 위에 두고 그 아래 흐름 6묶음. 제목 아래 '핵심만 먼저'(지금의 '짧게 말하면'), 경로 칩, 캡처는 sunken 매트. 꼬리는 도움이 됐나요 · 다음에 볼 문서 · 해결이 안 되셨나요 셋.
- **검색**: 오타는 고친 말로 찾고 '원래 말로 검색' 링크를 둔다. 문장형 질문이면 위에 챗봇 답변 미리보기(출처 문서 표시). 0건이면 챗봇 · 비슷한 문서 · 상담.
- **모바일**: 홈은 검색 → 처음이라면 3줄 → 증상 2열. 문서 화면은 플로팅 CTA 대신 '이 문서의 순서 · 가이드 목록' 바(R6).
- **유튜브 재생목록 주소는 저장소에 없다**(`grep` 결과 0). 운영팀이 주소를 정하면 `lib/` 상수 하나로 넣는다(§7 D7).

## 8. 문체 기준 — 번역체·AI체 덜기(2026-11-10 피드백)

가이드는 읽는 글이 아니라 막힌 사람이 보는 안내다. 말하듯이, 짧게, 행동부터 쓴다.

| 피하는 표현 | 이렇게 |
|---|---|
| 무엇이 막혔나요? / 필요한 안내를 바로 찾으세요. | 클래스인 사용 가이드 · 궁금한 내용을 검색해 보세요 |
| 증상을 누르면 먼저 해 볼 것부터 나옵니다. | 자주 막히는 문제부터 확인해 보세요. |
| 단어도, 문장도 됩니다 | '녹화가 안 돼요'처럼 문장으로 물어봐도 괜찮아요. |
| 수업 순서대로 묶었습니다. | 하려는 일을 찾아보세요. |
| 도입을 검토 중이라면, 사용법보다 이쪽이 먼저입니다. | 도입을 고민 중이신가요? |
| 이 안내로 해결됐나요? / 그래도 안 되면 | 도움이 됐나요? / 해결이 안 되셨나요? |
| 짧은 답 · 가이드 2편을 바탕으로 챗봇이 정리했습니다 | 챗봇 답변 · 가이드 2개를 참고했어요 |
| '녹화'로 고쳐 찾았습니다. | '녹화' 검색 결과예요. |
| 요점 / 짧게 말하면 | 핵심만 먼저 |

- 화면 머리(제목·묶음 이름)는 명사형, 안내 문장은 '~해 보세요 · ~예요'를 기본으로 한다. 문서 본문 단계는 지금처럼 '~합니다'를 유지한다.
- '먼저 해 볼 것', '하는 법', '~하는 곳'처럼 영어 직역 같은 명사구를 묶음 이름으로 쓰지 않는다.
- 사용자 말투 그대로인 증상 이름('로그인이 안 돼요', '녹화가 안 됐어요')은 그대로 쓴다 — 검색어와 같은 말이라 찾기도 쉽다.

## 9. 구현 순서(D1 = E일 때)
