# 클래스인 이해 기준 (What is ClassIn) — 에이전트용

기준일: 2026-06-29
문서 목적: 에이전트가 클래스인을 *홈페이지 카피 수준*이 아니라 *사업 수준*으로 이해하기 위한 기준. **출처 = 가이드·챗봇 문서(`lib/docs.ts` ~60개) + 리드마그넷(`data/lead-magnets.json` 13개)를 역추출**(2026-06-29). 마케팅 표면이 아니라 운영·영업 콘텐츠가 드러내는 진짜 클래스인.

> 캐논 인덱스: [README.md](./README.md) · 회사 팩트: [company-facts.md](./company-facts.md) · 보이스: [voice-charter.md](./voice-charter.md)

## 1. 한 문장
전자칠판 한 대가 아니라 **한 학원의 수업이 돌아가는 방식 자체를 하나로 묶는 "수업 시스템 OS"**. 핵심 명제(코퍼스에서 22회 반복): "좋은 수업이 에이스 강사 개인기에 의존하면 안 된다 → 시스템으로 표준화."

## 2. 제품 실체 (콘텐츠가 실제로 가장 많이 다루는 순)
1. **녹화·복습 흐름** — 단일 최다 언급(녹화 345·복습 130·다시보기 63). 무게중심이 여기다.
2. 실시간 수업 운영(코스/수업)
3. **EDB 교안** — 판서·이미지·텍스트가 "살아있는" 칠판 파일(최대 50p), 우수강사 템플릿 재사용
4. 하드웨어 — Classin Board + **OPS 내장 PC** + T1/S1 추적 카메라 + DT2 Pro 천장 마이크
5. 관리자 콘솔·권한 기반 데이터 가시성
6. LMS 학습활동 9종(숙제·시험·녹화수업·OMR·SCORM + AI 따라읽기/받아쓰기)
7. 30+ 교실 도구(개인칠판·타이머·퀴즈·그룹토론)
8. AI 보조(채점·출제·튜터 — 항상 "보조"로 hedge)

## 3. 고객 페인 (빈도순 = 영업이 실제로 찌르는 순서)
1. **도구 분산** — "학생 한 명 보려면 도구 다섯 개". 모든 페인의 뿌리.
2. **반복 운영업무** — 녹화 업로드·복습 배포·자료 재호출·출결. "장비가 늘면 손이 더 간다."
3. **강사 개인기 의존 / 퇴사 리스크** — "에이스가 나가면 그 반은."
4. **반별 품질 편차** — 같은 교재 다른 결과. *학부모 불만 나야 비로소 보임* = 숨은 구매 동인.
5. 휘발되는 판서·풀이(결석/복습생에 같은 품질 전달 불가)
6. 구형 전자칠판 페인(외장PC·HDMI·케이블·라이선스 만료)

## 4. 영업 모션 (리드마그넷 salesPlaybook이 드러낸 실제 엔진)
- **바이어 = 운영 의사결정 라인** (원장 최종 · 실장/교무 검증 · IT는 API 단계만 동석). 교사에게 팔지 않는다. **다자 의사결정.**
- **인텐트 사다리 = 13개 마그넷 `intentScore` 22→37** 이 곧 깔때기. 최고점(37)은 "도입 전 22질문"(리스크 검증 시작 = 구매 임박).
- **qualification 3종**: ① 현재 도구 스택 ② 최대 병목 ③ 첫 파일럿 교실/대수. 항상 *전체 도입이 아니라 1개 교실 파일럿*으로 좁힌다.
- **클로징 무기 = 데모가 아니라 "고객이 자기 대표 수업 자료를 들고 목동 쇼룸에 오게 만드는 것"**. `consultationPrep`이 항상 "대표 수업 1개 + 교실 사진 + 줄이고 싶은 반복업무 3개"를 가져오게 함 → 고객이 자기 맥락을 투자 = 진짜 의향 신호.
- **followUp**: D+0 5분(병목 질문+CRM 태깅) → 당일 콜 → D+1 자료 요청 → D+3 견적·90일 로드맵.

## 5. 반론 처리 (핵심 로직)
- **Zoom이면?** — "줌은 화상회의 중심. 한국 학원은 학생이 개인기기를 꺼려 → 판서→녹화→다시보기→LMS를 한 곳에 남기는 게 현실. 줌은 이 흐름을 못 남긴다."
- **전자칠판 있는데?** — "더 큰 화면은 이유가 안 된다. 차이는 디스플레이가 아니라 그 뒤 운영 흐름. 칠판이 아니라 칠판 뒤 운영을 바꾸는 결정."
- **비싼데?** → **TCO 리프레임**: 칠판만 사면 녹화장비·PC·과제/복습/관리 도구를 따로 사고 그 사이를 사람이 손으로 잇는 시간이 운영비로 쌓임. 비교 단위 = 보드+OPS+카메라·마이크+설치+SW+온보딩 *한 세트*.
- **가격** — 절대 금액 단정 안 함 → 규모 확인 → 패키지 안내 → 상담 확정.

## 6. 정직한 한계 = 영업 전략 (반복 명시)
약한 5영역을 *대놓고* 인정 → 신뢰 무기: **결제·정산 / 오프라인 출입·출석 / 고급 경영 리포트 / 자체 CRM·ERP**. "별도 시스템 또는 공식 API·커스텀 리포트로 역할 분담이 정직." AI도 "보조지 최종 정답 아님"으로 디하이프.

## 7. 진짜 차별점 (백엔드)
**EDB 교안 + 50p 칠판 + OPS(윈도우) + 녹화→LMS→상담 데이터 연속성**의 "끊김 없음". 모든 데모가 이 4개의 연속성을 증명하려 한다. → **EDB가 진짜 도입 레버**(하드웨어가 아니라).

## 8. ICP (코퍼스가 드러낸 실체)
- **스펙트럼**: 현장형 보습(학생이 개인기기 안 씀 → 그래도 판서·녹화·복습 가치) → **다지점·프랜차이즈·온라인** 확장 학원.
- **高가치 = 다지점·온라인·AI리포트 학원**(단일 보습 아님). data/API 자동화·강사 표준화 마그넷이 최고 인텐트대에 포진.
- 과목 단서: 국어(첨삭)·영어(자동채점)·과학(반별평가)·입시(고난도 판서). 규모: multi-강사/multi-반/정규+특강/다지점.
- **현장 우선(offline-first) 한국**: BYOD 없이도 가치가 나온다는 게 핵심 전제.

## 9. 지뢰밭 (단정 금지 — 영업 리스크)
- **서버 위치·콘텐츠 소유권** = "확인 필요, 단정 금지"(중국 추정조차 단정 불가).
- **API sync gotcha**: API 활성 기관이 콘솔에서 코스를 새로 만들면 자체 시스템과 자동 동기화 안 됨 → 자체 시스템에서 생성해야.
- "3개월 도입"은 정직하게 bounded(넓은 기관 6개월~1년). 재등록·강사 ramp 수치는 illustrative(보장 아님).
- 가격·기관수·밸류·모델스펙 단정 금지(→ [company-facts.md](./company-facts.md) 등급/상담).
