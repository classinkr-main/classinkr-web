## 1. 회사 개요
- **법인명:** EEO(Empower Education Online). 중국 베이징 기반 글로벌 에듀테크.
- **제품:** ClassIn — 온라인 라이브 교실 + 오프라인 스마트 교실 + LMS + 전자칠판(Classin Board).
- **한국 법인:** 이이오클래스인코리아(2022 진출, 국내 학원·교육기관용 SaaS).

## 4. 신뢰도 등급 — 표현 가이드
- ✅ **자유 사용:** 위 §2 Series C $265M(2020, Hillhouse/Tencent/SIG), §3 공식 스케일(160국·6만기관·3,000만 월간·2억 누적), 한국법인 2022.
- △ **약하게만 (정성 표현, 하드 수치 금지):**
  - **"에듀테크 유니콘"** — 언론에 'EdTech Unicorn EEO' 언급 존재하나 **$1B+ 밸류 공식 확인 안 됨.** 포지셔닝 수사로만 쓰고 밸류 금액 단정 금지.
  - **교사·학습자 수** — classin.com 미기재. 외부 출처 편차 큼(2천만~3천만+). **보수적으로 "2,000만+"** 사용. EEO 공식 최신 수치 확보 시 갱신.
- ❌ **사용 금지 / 수정 대상 (공개 기록과 불일치):**
  - ~~"시리즈 D"~~ → **시리즈 C** (D 라운드 공개 기록 없음)
  - ~~"누적 5억 달러 이상"~~ → **~$330M (시리즈 C $265M)**
  - ~~"5,000만+ 교사·학습자"~~ → **2,000만+** (50M은 어떤 공개 출처보다 높음, 미검증)
