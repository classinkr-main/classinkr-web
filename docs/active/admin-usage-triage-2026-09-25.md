## 0. 한 줄 요약

Home 어드민에는 사람이 쓴 흔적이 거의 없다. 최근 30일 이름 있는 관리자의 쓰기는 문서 편집 1건이고,
영업·마케팅 매니저는 리드 응대·전화를 Compass(마케팅팀 CRM)에서 한다(같은 기간 Compass 활동 600건 이상).
반면 Home에만 있는 원천(NEO 계정·KR Team 시트)은 동기화가 4~5주째 멈춰 있는데 화면이 그 사실을 말하지 않았다.
그래서 이번 정리는 **탭을 지우지 않고 숨기고, 멈춘 원천을 화면에 드러내고, 되살릴 것은 코드보다 운영 조치부터** 한다.

## 1. 실측 방법과 한계

- **방법**: 운영 서울 DB를 읽기 전용(Management API `read_only`, `transaction_read_only=on` 확인, SELECT 외 거부)으로
  집계했다 — 테이블별 총 행, 7·30·90일 생성, 마지막 쓰기, 작성자 컬럼이 있으면 관리자별 건수. 코드 쪽은
  `app/admin/**/page.tsx` 65개(실제 화면 46 + redirect 스텁 19)의 60일 커밋·인바운드 링크·중복 기능을 봤다.
- **한계**: 어드민 화면 **열람**은 기록되지 않는다(`client_events`에 `/admin` 행 0). 읽기 전용 화면(Overview·CRM 현황·
  Analytics·트래픽 등)은 DB로 판정할 수 없다. 작성자 컬럼이 없거나 비어 있는 테이블이 많다(블로그 작성자 id 전부 null 등).
  Compass(`crm` 스키마)의 쓰기는 Home 사용이 아니라 **매니저의 실제 업무 위치**를 보여 주는 증거로만 썼다.
- 이 문서는 개인별 로그인·활동 기록을 싣지 않는다 — 역할 단위로만 적는다.

## 3. 멈춘 원천 — 운영 조치 필요(코드 아님)

| 원천 | 사실 | 풀리는 방법 | 이번 라운드 코드 조치 |
|---|---|---|---|
| NEO 읽기 동기화(`sync-external-crm`) | 06-22부터 크론 34회 모두 "base URL 누락"으로 **건너뜀** — 자동 성공 0회. 마지막 수동 성공 08-28 → 원천 고객·360 매출·갱신 임박·매칭이 4주 전 값 | 운영 env `XIAOSHOUYI_BASE_URL`(+토큰) 설정, 쿼리 카탈로그 1행 확인 | 원천 고객·검수 상단 동기화 경고 띠. CRM 홈·검수의 "최신 동기화 시각"이 건너뜀 실행 시각을 쓰던 결함 수정(성공 실행만) |
| KR Team 시트(`sync-branch` REV/DSH/KPI) | 08-28(수동)·09-01(크론)부터 "시트 권한 없음"으로 전부 실패(30일 28회), 마지막 성공 08-18. HW는 정상 | 서비스 계정에 시트 공유 권한 재부여 | KR Team·매출 장부·REV 시트 상단 경고 띠, 장부 상태 줄의 원문 오류를 분류 문구로 |
| CRM 개요 스냅샷 | `refreshed_at` 09-15에서 정지 | 결함 아님 — 조회 시 1시간 넘은 스냅샷은 재계산하는 구조인데, 09-15 뒤 CRM 개요를 연 사람이 없었다 | 없음(기록만) |
| 기타 | 지사 인사이트 09-15 이후 새 행 없음, Google·네이버 광고 일별 0행, 주간 마감 09-04 이후 기록 없음 | 원인 미확인 — 광고는 자격증명·검수 대기([활성화 런북](ad-channel-activation-runbook-2026-09-14.md)) | 없음 |

경고 띠(`components/admin/SyncHealthBanner.tsx`, 판정 `lib/admin/sync-health.ts`)는 원문 오류를 싣지 않고
권한 / 설정 누락(env) / 네트워크 / 기타 분류와 "누가 무엇을 하면 풀리는지"만 말한다. 운영 상태(`/admin/ops`)에도
같은 원천 요약이 있다.

## 4. 탭 판정

판정 기준: 사람 쓰기 흔적(§2) × 코드 활동(60일 커밋·인바운드 링크) × 다른 화면과의 중복.
인터랙티브 판정 보드: [어드민 탭 정리 보드](https://claude.ai/artifact/QC4pYXxM5Juy1uDNXBJUik).

### 4.1 이번 라운드에 적용한 것 (되돌리기 쉬움, 링크 호환 유지)

- **기본 숨김**: 마케팅 프로젝트, 운영 상태 — 사이드바 "숨긴 탭 N · 보기"로 접히고 ⌘K·주소로는 열린다([탭 재구성 §15](admin-tab-restructure-2026-07-29.md)).
- **매니저별 숨기기**: 본인 "사이드바 편집"(상시 | 기타 | 숨김), SUPER_ADMIN은 설정 › 회원.
- ⌘K: CRM 태그·접수 추가, 견적 자식 3개를 스텁을 거치지 않는 최종 URL로, "이메일 자동화" → "메시지", 캠페인 관리·마케팅 프로젝트 자식,
  "내 사이드바 편집" 명령(전역 팔레트와 CRM 팔레트 모두).
- 모바일 헤더 라벨: 태그·접수 화면이 "고객 360"으로 나오던 오표기 수정.
- 라벨 통일: `deals/rev-sheet` = "매출시트"(옛 "REV 스냅샷"은 검색어로 유지).
- 옛 경로 링크 교정: 캘린더 헬스, REV 동기화 건강(파트너 → `/admin/crm/deals/kpi/{id}`). redirect 스텁 19개는 북마크 보호로 유지.
- 삭제: 설정의 "준비중"만 남은 CTA·변경 이력 섹션(옛 `?tab=` 값은 외부 연동으로 폴백), 가져다 쓰는 곳 없는 `AdminComingSoon.tsx`,
  공개 테스트 페이지 `/channel-test`(인바운드·사이트맵·noindex 없음, 방문만으로 채널톡 테스트 프로필이 열리던 페이지).

## 6. 심폐소생 — 대부분 "만들기"가 아니라 "켜기"

| 순위 | 대상 | 멈춘 이유 | 되살리는 최소 단계 | 누가 |
|---|---|---|---|---|
| 1 | NEO 읽기 동기화 | 운영 env 누락 | env 2개 + 쿼리 카탈로그 1행 | 운영(배포 설정) |
| 2 | Meta 캠페인 자동 동기화 | 캠페인 관리의 동기화가 버튼 전용 — 최근 30일 집행 Meta 4개 중 2개 미연결로 한눈에 스코어보드가 누락 | `sync-meta-insights` 크론 끝에 동기화 계획 적용 호출 1줄 | 코드(S) |
| 3 | 설명회 참석 명단 입력 | 입력함·출신 매트릭스는 완성, 운영 개시 안 됨 | 설명회를 공개 행사로 등록 → 명단 1건 시범 | 운영 |
