## 0. 검증 출처와 신뢰 규칙

- 본 인벤토리의 도구·활동 명칭은 **실제 제품 화면 캡처(2026-05-30, 2026-06-16)**와 공식 사이트(classin.com)에서 확인한 값이다.
- 2026-06-16에 추가 확보한 PDF 매뉴얼은 기능 흐름 참고용으로만 사용한다. 강사용·관리자용 매뉴얼은 2023-10-25 생성, 학생용 매뉴얼은 2023-05-02 생성 자료이며 최신 앱 UI와 다를 수 있다.
- 강사용·관리자용 PDF는 이미지 기반 자료라 자동 텍스트 추출이 되지 않았다. 화면 위치·버튼명은 최신 앱 캡처와 실제 제품 화면을 우선한다.
- ClassIn Board S 시리즈의 안전·기본 조작 안내는 `ClassIn Board S系列说明书`를 한국어 운영 기준으로 정리한 [S 시리즈 안전 사용 기본 지침](./classin-board-s-series-safe-manual-guidelines.md)을 따른다.
- LLM이 정리한 일반 설명에서 나온 명칭(예: "슬롯머신", "포커스 모드", "수식 입력기")은 **실제 UI에서 확인되지 않았다.** 아래 6절의 금지·주의 목록을 따른다.
- 명칭이 캡처와 다르면 캡처를 우선한다. 새 캡처가 생기면 이 문서를 먼저 갱신하고, 그다음 `lib/docs.ts`에 반영한다.

## 1. 활동 게시하기 (활동 유형)

교사가 단원에 추가하는 학습 활동 유형. 캡처상 3개 그룹으로 묶여 있다.

| 그룹 | 활동 유형 |
| --- | --- |
| 일반 활동 | 수업, 숙제, 시험, 녹화 수업, 학습 자료, 일일 과제, 토론, OMR 카드, SCORM |
| AI 기반 영어 교육 | 따라읽기(HOT), 받아쓰기, 외워말하기 |
| AI 기반 중국어 교육 | 따라읽기, 받아쓰기, 외워말하기 |

- 수업 설명 문구: "다양한 실시간 상호작용과 수업 후 AI 분석 및 요약 지원"
- 숙제 설명 문구: "유연한 과제 형식 호환 및 AI 자동 채점 지원"
- 어학 활동(따라읽기·받아쓰기·외워말하기)은 **영어/중국어 두 언어**로 각각 제공된다. docs에서는 언어 구분을 명시한다.
- TeacherIn 팝업은 앱에서 확인됐지만 캡처상 버튼 라벨과 세부 기능이 확인되지 않았다. 공개 문서에는 세부 동작을 단정하지 않는다.

## 2. 교실 도구 팔레트 (수업 중 도구)

실시간 교실 안에서 호출하는 도구. 캡처 기준 확인된 항목만 적는다. 노출되는 도구는 기관 스위치 설정에 따라 달라질 수 있다.

| 묶음 | 도구 |
| --- | --- |
| 진행 보조 | 타이머, 스톱워치, 주사위, 랜덤 선택 |
| 판서 | 보조 칠판, 개인 칠판, 레이저 포인터, 판서 저장/공유, 파일 열기 |
| 보상·순위 | 트로피 순위 |
| 화면·자료 | 화면 공유, 미러링, VNC, 브라우저, 다방향 브라우저, 비디오 갤러리, 수업 자료 라이브러리 |
| 카메라 | 보조 카메라 (듀얼 POV) |
| 참여 | 객관식 퀴즈, 선착순 퀴즈, 그룹 토론, 공동 작업, 실시간 채팅 |
| STEM·체험 | 화학 실험, 물리 실험, 기하도형, 측정 도구, 바둑 칠판 |
| 교실 내 호출 | 숙제, 시험, AI Board |

메모:

- "랜덤 선택"이 무작위 발표자 지정 도구다. (속칭 슬롯머신이 아니라 정식 명칭은 **랜덤 선택**)
- "다방향 브라우저"는 여러 학생이 동시에 조작하는 협업형 브라우저다.
- "보조 카메라"가 듀얼 POV(실물 교구·손동작 별도 송출)를 담당한다.
- 화학 실험/물리 실험/기하도형/측정 도구가 STEM 가상 실험·작도 도구다.

## 3. 발표·녹화·하이브리드 수업 개념

- 온스테이지: 고정형 카메라 레이아웃처럼 교사·학생을 수업 화면의 무대 영역에 띄우는 개념이다. 화면 상단에 고정되는 형태로 보이며, 스테이지 영역은 학생이나 교사가 숨기거나 작게 보여 칠판 화면을 넓게 쓸 수 있다.
- 온스테이지 인원수는 수업 생성 시 1v0~1v12 등으로 설정한다. 좌측 숫자는 교사, 우측 숫자는 학생 온스테이지 수로 설명한다.
- 학생 자동 온스테이지: 학생을 온스테이지 슬롯에 자동 배치하는 설정으로 설명한다. 카메라·마이크를 강제로 켠다고 단정하지 않는다.
- 권한 부여: 특정 학생에게 칠판 판서·드라이브 자료 발표 권한을 줬다가 회수할 수 있다.
- 수업 녹화: 온라인·오프라인 여부와 무관하게 기본 복습/다시보기 용도로 가장 많이 쓰는 기본 녹화다. ClassIn 교실 안의 칠판·자료·수업 화면을 중심으로 녹화하며, 교실 안에서 카메라를 켜면 ClassIn 화면 레이아웃에 포함된 카메라 영역도 함께 보일 수 있다.
- 현장 녹화: 기본 수업 녹화와 병행해 연결된 카메라가 촬영하는 실제 교실 뷰나 트래킹 뷰를 별도로 녹화한다. 다시보기에서는 수업 녹화와 현장 녹화를 따로 선택해 볼 수 있다.
- 하이브리드 수업: 앱의 토글 명칭이다. 기능 옵션으로는 학생이 실시간으로 칠판 화면과 현장 카메라 화면 중 원하는 뷰를 선택해 볼 수 있게 하는 설정이다. 운영 모델로는 온·오프라인 병행 수업 전체를 뜻한다.
- BYOD + 개인 칠판: 학생이 개인 패드나 기기로 접속해 문제를 받고, 교사가 학생별 풀이를 한 화면에서 확인하며 피드백·상점을 줄 수 있는 고활용 시나리오다. 기본 배포 흐름은 칠판 → 수업 도구 → 개인 칠판 → 그림판 → 배포.
- 기본 설정 예시: 칠판 중심 수업은 수업 녹화 ON을 기본으로 두고, 패드 수업이나 원격 학생이 없는 순수 현장 칠판 수업은 온스테이지 1v0 구성이 자연스럽다. 현장 뷰나 트래킹 뷰가 필요하면 현장 녹화를 병행한다.

## 4. 관리자 콘솔 대시보드와 메뉴 구조

관리자 웹 콘솔(`console.classin.com`)의 최신 캡처 기준 확인된 메뉴 구조. 관리자용 PDF보다 실제 화면 캡처를 우선한다.

| 1차 메뉴 | 하위 메뉴 |
| --- | --- |
| 홈 | 계정 잔액, 서비스 버전, 진행 중인 코스, 교사, 학생, 공지사항 |
| 기관 관리 | 코스 관리, 수업 관리, 공개 수업, 교사, 학생 |
| 스토리지 | 데이터 개요, 공유 드라이브, 문제 은행, 수업 리소스, 코스 데이터, 리소스 센터 |
| 학습 관리 | 라이브&플레이백, 학습 데이터, 교사 개발, 숙제 관리, 시험 관리 |
| 관리자 기능 | 수업 모니터링, 사용자 정보 |
| 결제 | 결제 개요, 주문 세부정보, 통계 다운로드, 영수증 관리 |
| 계정 정보 | 인증 자료, 일반 설정, 통계 이력, 권한 관리, API 도킹, 학습 인원 구성, 제품 설명서 |

메모:

- 홈 카드에서 계정 잔액, Business 버전, 서비스 기간, 진행 중인 코스 수, 교사 수, 학생 수를 확인할 수 있다.
- API 기능이 활성화된 기관은 관리자 콘솔에서 코스·수업·교사·학생을 새로 생성해도 자체 관리 시스템과 자동 동기화되지 않는다는 경고가 표시된다. 연동을 유지하려면 자체 관리 시스템을 통해 생성해야 한다.
- 관리자 문서와 챗봇 답변에서는 "관리자 대시보드"와 "관리자 콘솔"을 같은 웹 관리자 영역으로 설명하되, 앱 안 코스 화면과 혼동하지 않게 구분한다.

## 5. 하드웨어(Classin Board) 핵심 차별점

도입 상담·하드웨어 docs에서 강조하는 연결성 포인트.

- **선·외장 PC 불필요**: OPS 컴퓨터 내장 → HDMI나 외부 선, 외장 PC 없이 보드 단독 구동.
- **윈도우 기반**: 호환이 한정적인 안드로이드 기반이 아니라 윈도우 기반 → 익숙한 프로그램·자료를 그대로 사용.
- **무선 미러링**: 교사·학생 기기 화면을 선 없이 보드에 송출.
- **클라우드 연결**: 수업 자료·녹화가 클라우드로 이어져 시공간을 넘나드는 수업, 쾌적한 연결성·수업 쾌적도 제공.

## 6. 명칭 금지·주의 목록

실제 UI에서 확인되지 않았으므로 docs 본문에 단정 서술하지 않는다.

| 쓰지 않을 표현 | 대체/처리 |
| --- | --- |
| 슬롯머신 | 정식 명칭 "랜덤 선택" 사용 |
| 포커스 모드 / 집중 유도 기능 | 별도 도구로 확인 안 됨 → 서술하지 않음 |
| 수식 입력기 | 확인 안 됨 → 기하도형·측정 도구로 대체 서술 |
| 팝업 퀴즈 / 스마트 투표 | "객관식 퀴즈", "선착순 퀴즈"로 서술 |
| 테스트 뱅크(문제은행) | 자동 채점은 단정 가능, 문제은행 제공 범위는 "기관 설정·계약에 따라 다를 수 있음"으로 표기 |

- 장시간 고정 화면은 잔상 위험이 있으므로 화면 보호·절전·수업 종료 후 화면 끄기를 권장한다.
