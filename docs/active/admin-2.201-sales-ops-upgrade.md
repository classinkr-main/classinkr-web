# Admin 2.201 Sales Ops Upgrade

기준 시점: 2026-05-20

## 목적

`2.201` 브랜치는 어드민 탭 이름을 크게 바꾸지 않고, 현재 화면을 실제 세일즈/비즈니스 업무에 더 도움이 되는 현황 관리 공간으로 고도화한다.

핵심 방향은 개인별 "오늘 할 일" 앱이 아니라, 팀 전체가 같은 숫자와 같은 상태를 보고 리드, 캠페인, 견적, 계약, 수납 흐름을 관리하는 운영 관제실이다.

## 적용 원칙

1. 탭 이름 변경은 최소화한다.
2. 화면의 첫 인상은 "작업 목록"보다 "팀 전체 현황"이어야 한다.
3. 급한 부분은 개인 TODO가 아니라 지연, 위험, 실패, 누락 같은 운영 리스크로 보여준다.
4. 모든 주요 객체에는 상태, 담당자, 단계, 최근 변경, 다음 전환 가능성이 보여야 한다.
5. AI는 아직 전역 어시스턴트로 확장하지 않는다. 캠페인 문구와 견적 생성 보조에만 제한적으로 둔다.

## 탭별 고도화 방향

| 현재 탭 | 유지할 이름 | 고도화 역할 |
| --- | --- | --- |
| Overview | Overview | 팀 전체 세일즈/운영 현황판 |
| CRM | CRM | 리드/고객 파이프라인과 지연 현황 관리 |
| 캘린더 | 캘린더 | 상담, 데모, 견적, 계약, 설치, 캠페인 일정 현황 |
| 견적·문서 | 견적·문서 | 견적에서 계약/수납까지 이어지는 매출 진행 관리 |
| 캠페인 | 캠페인 | 캠페인별 리드, 상담, 견적, 매출 기여 관리 |
| Analytics | Analytics | 퍼널, 팀, 캠페인, 매출 판단 지표 |
| 회원 관리 | 회원 관리 | 권한, 역할, 감사 로그 관리 |

## 1단계: 편의성

### Overview

팀원이 어드민을 열었을 때 회사 전체 상황을 빠르게 읽는 화면으로 바꾼다.

투입 항목:
- 이번 주/이번 달 리드 현황
- 리드 상태별 분포
- 담당자별 보유 리드 수
- 급한 리스크: 미응답, 지연 견적, 계약 대기, 수납 확인, 실패 큐
- 캠페인 진행 요약
- 견적, 계약, 수납 요약
- 연동 오류와 데이터 누락

팀원 입장에서 바뀌는 점:
- 대표/관리자는 리드와 매출 흐름을 한 화면에서 본다.
- 영업팀장은 누가 어떤 단계에서 막혀 있는지 본다.
- 마케팅 담당자는 캠페인이 리드와 상담으로 이어지는지 본다.

### CRM

리드 목록을 단순 조회하는 화면에서 전체 파이프라인 관리 화면으로 바꾼다.

투입 항목:
- 상태별 리드 수
- 담당자별 보유 리드
- 오래 멈춘 리드
- 팔로업 지연 리드
- 단계별 전환 필요 리드
- 연락 로그와 상태 변경 이력

### 공통 상태 체계

화면마다 다른 상태 언어를 줄이고 공통 감각을 만든다.

권장 상태:

```text
신규
진행중
대기
지연
위험
완료
실패
```

## 2단계: 기능성

### CRM 퍼널 뷰

탭 이름은 `CRM`으로 유지하되 내부에 퍼널/칸반 관점을 추가한다.

권장 단계:

```text
신규
연락중
상담예약
데모완료
견적발송
협상중
계약대기
계약완료
보류
실패
```

### 캘린더

개인 할 일보다 팀 일정과 마감 현황 중심으로 정리한다.

투입 항목:
- 상담 일정
- 데모 일정
- 견적 마감
- 계약 서명 마감
- 수납 확인
- 설치 일정
- 캠페인 일정
- 팀별 일정 밀도

### 견적·문서

문서 보관함이 아니라 매출 진행 현황 화면으로 강화한다.

핵심 흐름:

```text
견적 작성
→ 발송
→ 고객 열람
→ 승인/수정 요청
→ 계약 전환
→ 서명
→ 수납
```

투입 항목:
- 견적 발송 상태
- 고객 열람 여부
- 승인/거절
- 계약 전환 여부
- 서명 상태
- 수납 상태
- 미수금
- 문서별 타임라인

### 캠페인

발송 완료 여부보다 성과와 전환을 중심으로 본다.

투입 항목:
- 캠페인별 리드 수
- 상담 전환 수
- 견적 전환 수
- 매출 기여 금액
- 세그먼트 저장
- 템플릿 관리
- 발송 실패/재시도 큐

## 3단계: 전문성

### Analytics

운영 숫자 조회를 넘어 경영 판단 지표로 만든다.

투입 항목:
- 리드 전환율
- 상담 전환율
- 견적 전환율
- 계약 전환율
- 캠페인 ROI
- 담당자별 처리 속도
- 팀별 파이프라인 금액
- 지연/위험 건수
- 월별 매출 흐름

### AI 제한 투입

전역 AI Assistant는 이번 단계에서 만들지 않는다.

허용 범위:
- 캠페인 제목 추천
- 캠페인 본문 초안
- 세그먼트별 문구 변형
- 견적 설명 문구 생성
- 고객 상황 기반 제안 문구
- 견적 후 팔로업 문구

제외 범위:
- CRM 전체 AI 요약
- 팀원별 평가
- 자동 의사결정
- 오늘 우선순위 추천

### 회원 관리

단순 계정 목록에서 권한과 감사 관리로 확장한다.

투입 항목:
- 역할별 접근 권한
- 리드 변경 로그
- 견적 수정 로그
- 계약/수납 상태 변경 로그
- 캠페인 발송 로그
- 자동화 규칙 변경 로그
- 데이터 export 로그

## 작업 순서

```text
1. Overview 팀 전체 현황판화
2. CRM 퍼널/담당자/지연 현황 추가
3. 공통 상태 체계 통일
4. 캘린더 팀 일정/마감 현황 강화
5. 견적·문서 매출 진행 관리화
6. 캠페인 성과/전환 관리화
7. 캠페인·견적에만 AI 제한 투입
8. Analytics 퍼널·팀·매출 지표 강화
9. 회원 관리 권한/감사 로그 강화
```

## 성공 기준

- 팀원이 탭 이름을 새로 외우지 않아도 된다.
- Overview만 봐도 이번 달 세일즈 상황과 급한 리스크를 읽을 수 있다.
- CRM에서 담당자별 병목과 지연 리드를 빠르게 찾을 수 있다.
- 견적·문서에서 문서 상태가 매출 진행 상태로 보인다.
- 캠페인에서 발송 결과가 리드와 견적 전환으로 연결된다.
- AI는 문안 작성과 견적 설명의 생산성을 높이는 보조 역할에 머문다.
