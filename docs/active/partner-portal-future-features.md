## A. 세일즈 인텔리전스

### A-1. 딜 스코어링
- 각 거래건에 AI 기반 성사 확률 % 표시
- 학습 기반: 단계, 마지막 연락일, 조회 횟수, 응답 속도, 규모
- 표시: `●●●●○ 78%`

### A-2. 딜 냉각 감지
- 트리거: 견적 발송 후 5일 이상 미조회 / 7일 이상 무응답 / 14일 이상 단계 변화 없음
- 알림: "학원B 거래 식어가고 있습니다. 오늘 연락 권장"

### A-3. 최적 타이밍 엔진
- 업종 패턴 학습 (방학 전 구매 집중, 월초 예산 확정 후 등)
- 발송 채널·시간대 자동 추천 (고객별 응답 패턴 기반)

### A-4. Next Best Action 큐
- 홈 우측 패널: "지금 가장 효과적인 행동" 제안
- 예: "전화 한 번 넣으세요 + 전화 버튼" / "카카오 리마인드 원클릭 발송"

### A-5. 파이프라인 예측
- 이번 달 예상 수납액 (확정 + 진행 중 가중치)
- 분기 목표 대비 현황
- 이탈 위험 거래 금액 합계

## B. 고객 행동 추적

### B-1. 견적서 열람 분석
- 단순 조회 여부 X → 항목별 체류 시간, 재조회 횟수 추적
- 링크 공유 감지 (다중 기기 접근 → 내부 공유 신호)
- 해석 레이어: "86인치 항목 4번 재조회 → 가격 고민 중"

### B-2. 반응 패턴 학습
- 고객별 응답 채널 선호도, 최적 응답 시간대 학습
- 발송 채널·시간 자동 추천

## C. AI 자동화

### C-1. 음성 → CRM 자동 입력
- 통화/미팅 후 음성 메모 → AI 요약 → activity_log 자동 생성
- 자동 추출: 교실 수, 예산, 결정권자 이름, 다음 약속일
- "방금 통화 내용 요약하시겠어요?" 원클릭 UX

### C-2. 번들 & 가격 추천
- 과거 성사 패턴 기반 번들 자동 제안
- "이 규모 학원 성사 평균 단가: 4,200만원"
- 분할 납부 플랜 자동 생성 (총액 입력 → 표준 분할 제안)

### C-3. 세일즈 코칭 레이어
- 실패 원인 패턴 분석 (가격/경쟁사/예산/시기)
- 성공 패턴 알림 ("레퍼런스 제시 시 성사율 2.3배")
- 개인 성과 트래킹 (전환율, 평균 완결 기간, 단계별 이탈률)

## D. 음성 오더 실행

### 개요
음성 명령 → STT → Claude function calling → 내부 API 실행

### 기술 스택
```
Web Speech API or Whisper (STT)
  → Claude API (intent 파싱 + function calling)
    → 내부 API 호출
      → TTS 피드백
```

### 허용 범위 (반드시 확인 단계 포함)

| 명령 | 허용 | 비고 |
|---|---|---|
| 미팅 기록 음성 입력 | ✅ | 가장 안전, 효용 높음 |
| 현재 거래 상태 조회 | ✅ | 읽기 전용 |
| 팔로업 일정 등록 | ✅ | |
| 견적 발송 (기존 문서) | ⚠️ | 확인 + 30초 취소 유예 필수 |
| 설치 완료 처리 | ⚠️ | 확인 단계 필수 |
| 견적서 신규 생성 | ❌ | 복잡도 높음 |
| 계약 서명 요청 | ❌ | 보안 이슈 |
| 금액 변경 | ❌ | |
| 삭제/취소 | ❌ | |

### 현실성 판단
- 효용성: 높음 (현장 파트너 대표, 이동 중 사용)
- 구현 난이도: 중간 (기술 스택 존재, API 연결만 하면 됨)
- 리스크: 확인 단계 설계로 관리 가능
- **지금 할 것: API를 음성 오더 연결 가능한 구조로 설계해두기**
