# 월별 목표·채움 차트 (3b)

KR Team 개요와 매출 장부 보드에 공용 `MonthlyGoalBowlChart`를 사용한다. 넓은 회색 막대가 승인 월 목표, 안쪽 좁은 막대가 확정·고확도·예정 금액이다. 예정에는 빗금을 사용하고 확도 색은 `CONFIDENCE_TOKENS`를 따른다. 기존 누적 페이싱·주차 차트와 보드 카드의 역할은 유지한다.

## 수치 계약

- 회계월은 4월~다음 해 3월이다. 월 목표는 기존 summary의 승인 DSH 누적 목표를 차분한다. 미승인 `0. DSH_NEW_TEMP`는 읽지 않는다.
- 월별 확도는 `lib/branch/monthly-goal-chart.ts`에서 `revenue-core.ledgerMonthSplit` 캐논으로 계산한다. 월 맵의 명시적 0, 음수 환불, 순액 0 상계와 원천의 색 정보 힌트를 보존한다. 적용 초안만 해당 월의 revenue 폴백을 허용한다.
- 상단 %는 지난달 **확정 ÷ 목표**, 당월 **(확정+고확도) ÷ 목표**, 미래 월 **(확정+고확도+예정) ÷ 목표**다. 당월은 커버리지이며 확정 달성률로 해석하지 않는다. 미래 월은 `~` 접두사와 회색 글자로 예상치임을 표시한다.
- 체크는 **확정액만으로 목표 이상**일 때 표시한다. 예상액이 목표를 넘었다고 체크하지 않는다. 목표 초과분을 100%에서 잘라내지 않는다.
- 양수와 음수 확도 합계는 공통 0선을 기준으로 나눠 그린다. 달성률·선택 월 상세에는 순액을 사용한다.
- 목표 누락·0 이하 또는 검색·담당자·상품 등 모집단 필터가 있으면 목표/달성률 비교를 생략한다. 필터 적용액을 팀 전체 목표에 나눠 임의 달성률을 만들지 않는다.

## 화면·원천 경계

- KR Team: 현재 팀의 REV 원천 행과 승인 DSH 목표를 사용한다. 읽기 실패를 0으로 표시하지 않으며, 저장된 원천을 쓰는 경우 기존 stale 상태를 표시한다. 장부 적용분과 원천 시트의 차이는 장부에서 검수한다.
- 매출 장부 보드: 기존 filteredRows(원천 시트+적용 장부)를 사용한다. 미적용 초안을 새로 합산하거나 조회하지 않는다. 월 클릭/Enter는 기존 selectedMonth와 URL 상태를 갱신하고 주차 보드도 같은 월을 따른다.
- 시안의 예시 데이터·팔레트는 집계에 사용하지 않는다. 시트·DB 쓰기, 동기화·마감은 수행하지 않는다.

모바일은 차트 안에서 가로로 탐색하며 선택 월을 가운데로 맞춘다. 월별 직접 라벨과 선택 월의 실제 금액은 hover 없이도 확인할 수 있다. 방향키는 월 사이 포커스를 옮기고 Enter/Space는 월을 선택한다. SVG pattern ID는 인스턴스별로 분리한다.
