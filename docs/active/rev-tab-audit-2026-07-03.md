# REV 탭(매출시트) 진단 & 개선 기획 — 2026-07-03

대상: `/admin/branch/ledger`의 REV 탭. 진단 방법: 3렌즈 병렬 감사 — ①데이터 정합성(코드 추적) ②사용자 경로(여정 재구성) ③실화면 검증(로컬 dev, `period=Y`, 398행/249고객 실데이터). 파일 참조는 repo-relative, 라인은 근사치(± 표기)이며 `WB` = [components/admin/branch/SalesLedgerWorkbench.tsx](../../components/admin/branch/SalesLedgerWorkbench.tsx).

P0 세 건(A1·A2·A6)은 오케스트레이터가 코드로 재검증 완료. 나머지는 각 렌즈 보고 기준이며 구현 착수 시 해당 라인 재확인 필요.

## A. 데이터 신뢰 — 숫자가 틀리거나, 같은 값이 화면마다 다름

### A1. 적용된 초안의 확도가 무조건 '확정'으로 집계 (최우선)
- WB ±3758-3805 (`ledgerEntryRows`/`appliedDraftFallbackRows`): 확도 3종(예정/고확도/확정)을 입력받아 저장하면서도, 적용 엔트리→행 변환 시 무조건 `monthlyConfirmed`+`monthlyRed:true`. WB ±665 `rowMonthConfirmed`도 draft origin이면 전액 확정 강제.
- 증상: "예정"으로 넣은 ¥50만을 적용하는 순간 셀이 확정 초록+잠금, footer 확정 스택·달성률·담당자/상품군 표 전부 상승. 월 확정 수치가 구조적으로 부풀려짐.
- 방향: entry/draft `metadata.confidence`를 읽어 확정/고확도/예정 버킷으로 분배. 잠금·톤·검수칩도 버킷 따라가게. (난이도 M)

### A2. 달성률 분모는 팀 목표 고정, 분자는 필터 반영 — 필터 걸면 % 전면 왜곡
- 분모: summary API 요청이 `?team=&period=(&month=)`만 전달(WB ±3732) → 담당자/지역/상품/검색이 목표에 반영될 수 없음. 분자: `filteredRows` 기반(WB ±3943-3948).
- 왜곡 표면: 레일 카드 달성률·"목표까지 부족"(±5577-5626), tfoot "월 목표 대비(확정)" %(±3367-3390), 주차표 pace/누적 달성률(±1664-1746).
- 증상: 팀 목표 ¥100만 달에 담당자 A(¥30만)로 필터 → "달성률 30%·¥70만 부족" 경고 — A 개인과 무관한 값.
- 방향: 필터 활성 시 %·부족액 숨김 + "팀 목표 기준 — 필터와 비교 불가" 배지. (S~M)

### A3. '확정'의 정의가 매트릭스와 레일 카드에서 다름
- 매트릭스/footer/보조표: `rowMonthConfirmed`(월합계만·일자추정 행도 red면 확정 포함). 레일: `buildRevWeekProjection`(±740-758)이 month-only/inferred 행을 확정 분해에서 제외 → 같은 달·같은 필터에 확정 두 숫자.
- 방향: projection의 확정 분모를 `rowMonthConfirmed`와 통일, 주차 분해 불가분은 별도 버킷 표기. (M)

### A4. 음수 금액(감액)이 표시 경로에서 0으로 소거
- WB ±652 `rowMonthAmount`가 `> 0`만 통과 → 셀/소계/tfoot/연간/보조표에서 음수 월 누락. 반면 정렬용 `revenue` 합산은 음수 포함 → 표시 합계 > 시트 합계, 정렬-표시 모순.
- 방향: 음수 통과+빨간 괄호 표기, 최소한 합계·정렬 경로 일치. (S~M)

### A5. DB-native 임포트가 레거시 red-불리언 행의 확정을 '예정'으로 강등
- [lib/repositories/sales-ledger-rev-import.ts](../../lib/repositories/sales-ledger-rev-import.ts) ±135: confidence 분해를 `monthly_confirmed` 금액 맵만 보고 계산 — `monthly_red=true`인데 맵이 빈 레거시 행은 전액 expected. 시트폴백(`rev-confirmed.ts`)은 red→확정이라 전환 전후 확정 합계 급감 가능.
- 방향: red=true && confirmed 빈 값 → 전액 confirmed 승격(폴백 규칙과 동일). (S)

### A6. "연간합계" 열의 정렬 키가 표시값과 다름
- 헤더 `sortKey="revenue"`(WB ±5844) = period 스코프 **확정 전용** 값. 표시값은 12개월 전체 확도 합. 연간 ¥300만(예정) 고객이 ¥50만(분기 확정)보다 아래로 정렬.
- 방향: `annual.total` 정렬 키 신설. (S)

### A7. 검수 인박스 칩 숫자 ≠ 클릭 결과 건수
- `revInboxCounts`(WB ±4015-4025)가 pre-filter `rows` 기준. 담당자 필터 활성 상태에서 "불일치 27" 클릭 → 목록은 교집합만. 주석의 "칩=결과 일치" 주장은 무필터일 때만 참.
- 방향: forecast 필터를 제외한 `filteredRows` 기준으로 카운트. (S)

### A8. 기타 표기 정합 (각 S)
- tfoot 연간 %: 분모가 '목표 있는 달만'이라 과대(±3385-3390) → 부분 목표 표기.
- footer 확도 스택 독립 반올림(±3332-3349): 부분합 표시가 셀 합계와 ±0.1만 어긋나 보임 → 합산 후 포맷.
- mixed 확도 셀이 '예정'과 동일 amber(±392) + 레전드 4종에 mixed 없음 → 그룹 소계·연간 셀이 상시 미확정으로 오독. mixed 전용 톤/표기.
- 잠금 라벨 "시트확정"이 장부 입력(적용 초안)에도(±423, 2724) → origin별 라벨 분리.
- 그룹 불일치 배지(12개월)와 레일 "주차 합산" 옆 불일치 N행(선택월 문맥, ±6353) 기준차 → 레일에는 선택월 기준 카운트.
- mismatch 허용오차 ¥1(±790): 반올림 누적 ±2~3원 오탐 추정 → 허용오차 상수화+툴팁 고지.

### A9. "월합계만 → W5 합산" 규칙이 pace를 구조적으로 왜곡
- 주차표 누적(±1729-1746)에서 월합계만 금액이 W1~W4에 없다가 W5 유입 → 월중 상시 "뒤처짐(빨강)", W5 항상 피크. 월합계만 비중 큰 달은 가짜 경고 내러티브.
- 방향: pace 계산에서 월합계만 금액 제외(+각주) 또는 일수 비례 분배. (M)

### A10. 레거시 주차 고정 오프셋 폴백(재동기화 전 행) — 주차 밀림 잔존 리스크
- [lib/branch/computations/pipeline.ts](../../lib/branch/computations/pipeline.ts) ±73-93. 재동기화 완료 시 소멸 — 재동기화 실행을 운영 체크리스트로. (운영 조치)

## B. 사용자 경로 — bad (끊김·위험)

### B1. 주차 셀 1칸 편집·적용 = 그 달 전체를 그 값으로 대체, 경고 전무 (최우선)
- 체인: `onCommitCell`(WB ±4361-4414, 단일 주차 amount로 초안) → 적용 → `editRowOverrideMonths`(±3831-3866)가 원본 행의 그 달 월/주차/확도 전부 삭제 → 대체 행 주차는 그 주차만(±2378-2383).
- 증상: 7월 W1=100·W2=200인 딜에 W3=500 입력·적용 → 7월이 500, W1·W2 증발. 툴팁·팝오버·적용 버튼 어디에도 고지 없음.
- 방향(2단): ①즉시 — 주차 편집 커밋·적용 시 "이 달 전체 대체" 경고 문구(S) ②본질 — 커밋 시 기존 주차 병합해 월 amount=나머지 주차 보존값으로 구성(M~L).

### B2. 편집 실패가 편집 지점에서 침묵 + 로컬 폴백은 적용 불가 막다른 길
- `createDraft` 실패 → 페이지 최상단 Source 바 인라인 ⚠칩만(±4935-4946), 매트릭스 시야 밖. 이후 로컬 초안(`local-*`)은 적용 거부(±1101-1104)인데 사용자는 계속 저장된다고 믿고 입력.
- 방향: 셀 인근 실패 토스트/배지 + 로컬 큐 전환 시 명시 배너("서버 연결 복구 후 재시도 필요") + 성공 시에도 최소 피드백(앰버 점 의미 온보딩 1회). (M)

### B3. API 실패가 "조건에 맞는 행 없음" 빈 상태로 위장
- 실패 시 `data=null·loading=false` → 빈 상태 문구+필터 초기화 유도(±5849-5867). 에러는 최상단 배너뿐, 제자리 재시도 없음.
- 방향: error 분기 신설(원인+재시도 버튼), 다중 실패 시 목록. (S)

### B4. 키보드만으로 편집 진입 불가
- 셀 `tabIndex=0`인데 `onKeyDown`이 미선택 셀 입력 무시(±2773-2776) — 클릭 선행 필수.
- 방향: 포커스 셀에서 Enter/F2 → `selectCell`. (S)

### B5. 편집→검수 큐 연결 단절
- 커밋된 초안은 우측 레일(기본 접힘 ±3434)에만, 진입은 우하단 스위처뿐. 검수는 1건씩 체크→적용, 체크된 초안은 삭제 거부(체크 해제 선행) — 순서 비고지.
- 방향: 매트릭스 상단 "미적용 초안 N건 → 검수" 칩(레일 오픈 링크) + 일괄 체크/적용. (S~M)

### B6. URL 동기화 비대칭
- 보존: 렌즈/월/기간/팀/검색/필터/정렬/페이지크기. 유실: 페이지 번호·주차 확장·그룹 펼침(±3588-3627) — 3페이지 검수 중 새로고침 시 1페이지 전부 접힘.
- 방향: `revPage` 최소 추가. (S)

### B7. 단축키 비문서화 + blur=커밋
- Tab/Ctrl+D(fill-down)/직입력 구현돼 있으나 안내 없음, 편집 중 외부 클릭이 취소 아닌 커밋(±2744-2747).
- 방향: 편집 모드 헬프 힌트 1줄 + Esc 안내. (S)

### B8. 신규 고객(forecast-add) 초안이 적용 전 매트릭스에 완전 불가시
- 행 소스가 applied만(±3746·3781) — "초안 넣었는데 표에 없음".
- 방향: pending/checked 초안 유령 행(점선+앰버) 표시. (M)

## C. 읽기 균형 — 언밸런스 (실화면 확인)

### C1. 스크롤하면 월 라벨과 합계가 동시에 사라짐 (최우선)
- thead sticky 없음 + tfoot `sticky bottom-0`(±3307)은 overflow-x-auto 래퍼 내부라 **실제로 고정 안 됨**(실화면: 중간 스크롤에서 footer 부재, 표 끝에서만 등장). 100행 기본과 결합해 "몇 월인지 모를 숫자벽" — 불일치 빨간 셀을 보고도 몇 월인지 알 수 없음.
- 방향: 매트릭스를 max-height+overflow-y 컨테이너로 감싸 thead sticky top/tfoot sticky bottom 실작동(레포의 body overflow-x sticky 함정 주의 — admin은 app-shell 스크롤). (M)

### C2. 상단 5타일 정보 중복
- 실적 ¥103.5만 = 장부 반영 ¥103.5만(동일 값 2회), GAP ¥-896.5만이 장부 반영 서브라인+GAP 타일 2회. 정작 예정 파이프라인(연 ¥821만)은 타일에 없음.
- 방향: [목표 | 확정(예정 서브라인) | 장부 신규·수정 | GAP | 입력 큐] 재구성 — 장부 반영 타일은 "DB 신규 N·수정 N"이 본문이 되게. (S)

### C3. 입력 큐 타일 원시 표기 ¥5,000 — 만단위 규약 이탈
- 다른 타일은 만단위(¥103.5만), 입력 큐만 ¥5,000. → formatMoney 통일(¥0.5만). (S)

### C4. "달성률" 동단어 이값 병존
- 타일 10.3%(FY) vs 보조 분석 2.4%(선택월) — 라벨에 기간 명시("FY 달성률"/"7월 달성률"). (S)

### C5. 만단위·원시 위안 혼재로 크기 인지 왜곡
- 같은 열에 "9.7만"과 "5,000"이 유사한 시각 무게(실화면: 학문당 행). 1만 미만 셀 시각 강등(소형·회색) 또는 "0.5만" 정책 결정. (S)

### C6. 주차 확장 시 그 달 '월 총액' 열이 사라짐
- 확장하면 W1~W5만 남아 월 합계는 암산 필요(실화면 확인). 확장 중에도 월 소계 서브셀 유지 검토. (S~M)

### C7. 페이지네이션 하단 전용 + 기본 100행
- "1/3" 페이지 바가 표 끝(±5919) — 100행 스크롤 후에만 도달. 상단 복제(S). 기본 100행(83e0b86)은 C1 해결 전까지 50 롤백 검토, 가상 스크롤은 백로그 유지.
- 실적 내림차순 기본 정렬상 뒤 페이지는 소액 온라인 행 도배 — 소액 임계 접기(그룹핑) 옵션 검토. (M, P3)

### C8. 소소한 강등 (각 S)
- 렌즈(DSH/REV/KPI) 설명이 hover title 전용(±4923) — 터치에서 의미 전달 불가.
- 딜 행 SW/HW·장부/시트 라벨 저대비 소형 텍스트(±3262-3268) — 툴팁 복원.
- 월 스테퍼 FY 밖 무제한 이동(±478-484) + period=M 시 데이터 소스 전환 가능 — FY 경계 clamp 또는 경고.

### 머지 게이트와의 관계
직전 머지 사전 리뷰(차단급 0)는 인증·이중계산·캡 방어 중심이었고, 본 감사는 그 아래층(집계 정의·확도 전파)에서 A1·A2·A5를 새로 발견함. **P0 4건 + B1 경고를 이 브랜치에서 처리한 뒤 머지**하는 것을 권장. 나머지는 머지 후 후속으로 무방.
