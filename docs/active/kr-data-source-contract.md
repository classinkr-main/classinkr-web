# KR 데이터·조직·목표 연결 기준

상태: 현재 연동 판단 기준. Admin 권한·삭제 정책은 [Admin OS 운영 결정](admin-os-operating-decisions-2026-07-11.md)을 따른다.
범위: NEO 본사 CRM, Compass, 홈페이지 Admin의 데이터 소유권·대사·목표 반영.

## 1. 조직과 이력

2026-10-15 사용자 확정: 문준혁·진소망은 MKT이며 CSM팀은 폐지됐다. 현재 팀 선택·신규 입력·정기 분석은 BD·MKT를 사용한다.
현재 조직의 코드 기준은 [current-organization.ts](../../lib/branch/current-organization.ts)다.

- 과거 장부의 CSM·CS 표기, 담당자, 수납·환불, 활동 작성자, 확정 평가 수치는 보존한다. 현재 부서 변경으로 과거 매출을 재귀속하지 않는다.
- CSM 조회는 이전 조직의 이력이다. 현재 평가·신규 업무 배정을 위한 팀으로 사용하지 않는다.
- 팀 폐지는 개인 삭제가 아니다. 개인의 새 부서가 미정이면 미분류로 남기고 KPI나 로그인 권한을 임의로 삭제하지 않는다.
- 현재 평가 명부는 Compass의 DB 설정을 읽는다. 두 사람의 운영 설정이 이전 부서라면 Compass 설정에서 정상 갱신하고 양쪽 화면을 확인한다. Admin에 개인명 예외를 추가해 별도 명부를 만들지 않는다.
- 명부에서 빠진 원본 평가자는 현재 인원 집계에서 제외하되 별도 원본 상세에 남긴다. Compass의 확정 평가 역할 표기는 현재 설정으로 붙을 수 있으므로 '평가 당시 부서'로 단정하지 않는다.

## 2. 무엇이 원본인가

| 데이터 | 원본·해석 | Admin 구현·주의 |
| --- | --- | --- |
| 본사 영업 실적 | NEO `SalesPerformance__c`의 본사 실적 지표 | [admin-crm-neo.ts](../../lib/admin-crm-neo.ts). 오더·수금과 별도 지표 |
| 본사 오더·수금 | NEO 기회/오더와 `Collection__c` 수금 | 원천별 통화·환율·기준일을 유지. 화면의 USD 오더와 CNY 수금을 무환산 합산하지 않음 |
| 지사 확정 매출·예정 | 활성 REV 임포트 → DB 미러 등 기존 원천 경로 | [read-rev-deals.ts](../../lib/branch/read-rev-deals.ts). 본사 실적과 별도 대사. 현재 CRM performance도 REV 기준 |
| 장부 목표 | 연결된 DSH·KPI 목표 미러 | 노션 개정 목표와 대조하기 전에는 최신 승인 목표라고 단정하지 않음 |
| 콜·데모·리드·액션 | Compass 원본 활동과 데모·리드 | Compass 집계기·근거 목록의 같은 술어를 사용. 부재중·노쇼·취소·BD 인계 경계를 보존 |
| 월별 가중 KPI | Compass 목표·가중치·수동 조정·정성 평가·확정 스냅샷 | [Compass 읽기 계약](compass-kr-team-sync.md). Admin에서 평가 산식을 복제하지 않음 |
| 연결·검수·권한 | Admin의 확정 소스 링크·검수·서버 권한 | [그로스 플레이북](playbook/04-growth-crm.md), [네오CRM 되밀기 지침](neocrm-writeback-guide-2026-09-07.md) |
| 개정 사업계획·하반기 목표 | 사용자가 지정한 최신 승인 노션 원문 | 아래 반영 절차. 예전 문서의 고정 숫자·가중치를 최신값으로 재사용하지 않음 |

같은 Supabase DB를 공유해도 데이터의 의미·소유권은 구분한다. Compass는 `crm` 스키마와 읽기 계약을 소유하고 Admin은 제한된 브리지 뷰와 서버 API로 소비한다.

## 3. 연결·대사 규칙

1. 고객명 일치만으로 매출을 합치지 않는다. 원천 시스템·객체·ID와 확정된 `crm_source_links`를 사용한다. 전화 키는 기존 정규화 규칙을 공유한다.
2. 비교 전에 통화, 금액의 의미(실적/오더/수금/예정), 매출 인식일, 회계연도·월, 취소·환불, 확정 상태를 맞춘다. 서로 다른 기준의 차이는 별도 금액으로 표시한다.
3. REV·NEO·Compass에서 같은 거래를 보더라도 세 금액을 합산하지 않는다. `confirmed` 연결만 중복 제거 근거로 사용한다. 미확정 연결은 검수 대상으로 둔다.
4. NEO 가져오기 스텁(`channel='neo'`)은 새로운 마케팅 유입이나 콜 성과가 아니다. 원래 마케팅 유입 리드의 채널은 보존한다.
5. 조회 실패·잘린 페이지는 정상 0건이 아니다. 명시적인 성공 응답의 빈 배열만 빈 원천으로 처리한다. 담당자 제외 목록을 읽지 못하면 한국 범위를 넓히지 않는다.
6. NEO 업무 오류나 불완전 응답으로 원천 전체를 stale 처리하지 않는다. 삭제·병합 이력은 기존 엔진을 따르고 정기 동기화가 삭제된 스텁을 되살리지 않게 한다.
7. 환불 음수와 월별 상계 합계 0을 보존한다. 월 합계와 팀·담당자 분해는 같은 확정 산식을 사용한다.
8. 상단 확정 매출·누적 추이·파이프라인·히트맵·KA/SME 분해는 [REV 확정 캐논](../../lib/branch/computations/rev-confirmed.ts)을 사용한다. DSH 실적은 DSH 출처로 표시하는 별도 비교값이다. 첫결제일 공란·월 순액 0만으로 명시된 확정액을 제외하지 않으며, 미래 무색상 금액의 예정 판정도 캐논을 따른다. 전사 목표는 승인 DSH의 ALL 행을 우선하고, 없을 때만 팀별 목표를 합산한다.

매출 분해의 제품·신규/갱신·채널 카드는 DSH 전사 실적이며, KA/SME 카드는 선택 범위의 REV 확정액이다. 두 원천을 섞어 확정 평균을 만들지 않는다. 분해 영역의 상단 확정액은 요약과 동일한 REV 값을 사용한다.

## 4. 노션 개정 목표 반영

2026-10-15 사용자 확정: 연결된 통합 장부의 `0. DSH_NEW_TEMP`는 조정 예정인 **미승인안**이다. 확정 목표·달성률·팀/개인 KPI·월별 배분에 반영하지 않는다. 현재 시트 목표 기준은 `1. DSH`이며, `4. 목표 전략`과의 대조도 이 기준을 유지한다. 임시 탭의 표 구조나 합계가 달라도 자동 채택하거나 승인된 노션 개정본으로 간주하지 않는다.

최신 사업계획서·하반기 목표의 페이지, 개정 시각, 승인 상태, 적용 기간을 먼저 확인한다. 기존 KPI v2.0 링크만으로 최신 개정본이라고 판단하지 않는다.

사용자가 지정한 원문:

- [ClassinKR 사업계획](https://app.notion.com/p/ClassinKR-3eb0469bf801804392d3e14d6d5f50cc?source=copy_link)
- [H2 목표](https://app.notion.com/p/H2-5ff0469bf80182199bda81854806f578?source=copy_link)

페이지 링크 지정은 원문 내용·개정 금액을 읽어 검증했다는 의미가 아니다. 본문 확인 전에는 값 반영을 보류한다.

반영안에는 원문 위치와 기존값 → 개정값, 통화, FY/반기/분기/월, 팀·개인, 총액·신규·갱신·SW/HW 분해를 함께 적는다. 원문에 없는 월별 배분을 임의로 균등 분배하지 않는다. 하반기를 달력 7~12월이나 FY Q3·Q4로 추정하지 않는다.

- DSH 매출 목표, Compass 개인·팀 평가 목표와 가중치, 사업계획서 채점 기준은 각각의 쓰기 소유자에서 갱신한다. 하나의 목표가 바뀌었다고 나머지를 자동 덮어쓰지 않는다.
- 진행 중인 달의 변경 사유·작성자·일자와 기존 KPI 감사·확정 규칙을 유지한다. 확정 스냅샷을 현재 목표로 재계산하지 않는다.
- 적용 후 팀 합계·개인 합계·월/분기/반기 합계, 음수·0·미설정, 양쪽 화면의 목표·달성률을 대조한다.
- 노션 원문과 연결된 H2 안내·MKT 작성 규칙·점검표를 읽을 수 있다. 다만 MKT 작성 규칙은 황찬우 하반기 목표 350,000 CNY와 DSH·KPI의 450,000 CNY가 다르다고 명시하며, H1 실적·일부 예상치는 미승인 `0. DSH_NEW_TEMP`를 참조한다. 문서의 과거 확정 표기만으로 사용자의 최신 미승인 지시를 뒤집지 않는다. 이 차이를 승인 DSH에 자동 덮어쓰거나 최신 개정 목표 반영 완료로 표시하지 않는다.

## 6. 채널 정산 읽기

`3. 채널 정산`은 연결된 통합 장부의 전사 파트너 정산 원본이다. 원본 Sheets는 읽기만 하며 매출·목표 합계에 수수료를 더하거나 차감하지 않는다.

- 계약금액(F)은 RMB/CNY, 원화 적용(G)은 KRW, 수수료율(H)과 지급액(I)은 각 원본 값과 누락을 유지한다. 원화 금액이 비었거나 환율 기준이 미정이면 임의 환산하지 않는다.
- 선택 기간은 결제일(J) 기준이며, 정산일(K)의 입력 여부를 별도로 표시한다. 정산일 공란은 미입력이며 실제 미지급·미정산 확정으로 단정하지 않는다.
- 현재 팀 필터와 별도로 전사 정산 범위를 표시한다. 담당자 이동으로 과거 정산의 팀을 추정하지 않는다.
- 파트너·기간 집계만 제공하고, UID·고객명·개인 연락처·결제 식별자는 정산 요약 API에 노출하지 않는다. 음수·명시 0·미입력·조회 실패·빈 기간을 구분한다.
