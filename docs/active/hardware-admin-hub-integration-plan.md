# Hardware Admin Hub Integration Plan

기준 시점: 2026-04-22

## 1. 목적

파트너 포탈을 별도 운영 제품으로 확장하기보다, 클래스인 팀원이 실제로 쓰는 하드웨어 영업/운영 기능을 어드민의 `하드웨어` 영역으로 통합한다.

파트너와 고객은 로그인형 포탈을 상시 사용하지 않는다는 전제에서, 외부 접점은 필요한 순간의 링크와 제출 폼으로 단순화한다.

## 2. 제품 판단

### 2-1. 핵심 방향

- 어드민 최상위 탭을 계속 늘리지 않는다.
- `/admin/hardware`를 하드웨어 영업/운영 허브로 만든다.
- 기존 파트너 포탈의 견적/문서/공유 링크 기능은 삭제하지 않고 어드민에서 재사용한다.
- 파트너 포탈은 "파트너가 매일 들어오는 업무공간"이 아니라 "외부 링크/제출/열람 엔진"으로 재정의한다.

### 2-2. 외부 사용자는 포탈 대신 링크를 받는다

- 견적서 공개 링크
- 계약서 서명 링크
- 재고/납품 정보 제출 폼
- 설치 정보 제출 폼
- 파일 업로드 링크
- 열람/동의 상태 추적 링크

## 3. 목표 IA

초기 목표는 `/admin/hardware` 안에 기능을 묶고, 하위 탭은 과도하게 쪼개지 않는다.

```text
/admin/hardware
  - 개요
  - 영업
  - 견적/문서
  - 재고/설치
```

### 3-1. 개요

- 신규 문의
- 상담 필요
- 견적 진행
- 계약 대기
- 설치 예정
- 재고 부족
- 오늘/이번 주 액션

### 3-2. 영업

- 하드웨어 리드
- 고객/기관
- 딜 단계
- 담당자
- 연락 로그
- 다음 액션

딜 단계 기본값:

```text
문의 -> 상담 -> 견적 -> 계약 -> 설치 -> 완료
```

### 3-3. 견적/문서

- 빠른 견적 작성
- 표준 견적 템플릿
- 견적 미리보기
- 공유 링크 생성
- 문자/카카오톡/이메일 발송 준비
- 고객 열람/동의 상태 추적
- 계약 전환
- 견적서/계약서/영수증/납품확인서 목록

### 3-4. 재고/설치

- 모델별 재고
- 입고/출고
- 예약 재고
- 계약 연결
- 설치 일정
- 설치 체크리스트
- 완료 사진/메모/이슈

## 4. 현재 기능 재배치

### 4-1. 어드민 기존 기능

```text
/admin/quotes
  -> /admin/hardware?tab=quotes 로 흡수

/admin/crm
  -> /admin/hardware?tab=sales 의 하드웨어 리드/딜 영역으로 일부 흡수

/admin/commercial
  -> /admin/hardware 개요와 영업 파이프라인에 요약 기능 흡수

/admin/hw-sales
  -> /admin/hardware?tab=sales 또는 /admin/hardware?tab=ops 로 흡수

/admin/install-schedules
  -> /admin/hardware?tab=ops 로 흡수

/admin/contracts, /admin/receipts
  -> 독립 탭을 당장 제거하지 않고, 하드웨어 문서 영역에서 관련 문서만 교차 노출
```

### 4-2. 파트너 포탈 기존 기능

```text
QuickQuoteComposer
  -> 어드민 하드웨어 견적/문서 탭의 빠른 견적 작성 UI로 재사용

quote_documents / quote_document_versions / quote_document_shares
  -> 공개 견적 링크, 버전 관리, 열람/동의 추적의 기준 데이터로 유지

/partner/quote/[token]
  -> 고객/파트너 외부 열람 링크로 유지

파트너 로그인형 업무 화면
  -> 장기적으로 축소 또는 숨김
```

## 5. 데이터 원칙

가장 중요한 리스크는 견적 데이터가 두 갈래로 나뉘는 것이다.

현재 흐름:

```text
어드민 단순 견적:
quotes / quote_items

문서형 견적:
quote_documents / quote_document_versions / quote_document_shares
```

권장 원칙:

- 고객에게 발송하거나 링크로 공유되는 견적은 `quote_documents` 계열을 기준으로 한다.
- `/admin/quotes`의 기존 단순 견적은 당장 삭제하지 않는다.
- 새 하드웨어 견적 UI는 문서형 견적을 우선 사용한다.
- 기존 `quotes / quote_items`는 마이그레이션 전까지 읽기/계약 전환 호환 레이어로 둔다.
- 재고 예약, 계약 전환, 설치 일정 연결은 문서형 견적의 확정 버전을 기준으로 잡는다.

## 6. 실행 단계

### Phase 0. 범위 고정

- `/admin/hardware`가 하드웨어 영업/운영 허브라는 제품 결정을 문서화한다.
- 기존 어드민 탭 제거는 하지 않는다.
- 파트너 포탈 외부 링크 기능은 유지한다.

완료 조건:

- 이 문서가 기준 계획으로 커밋되어 있다.

### Phase 1. 하드웨어 허브 껍데기

- `/admin/hardware` 라우트를 만든다.
- 개요/영업/견적 문서/재고 설치 하위 탭 구조를 만든다.
- 기존 화면으로 이동하는 링크를 우선 연결한다.
- 기존 기능은 아직 옮기지 않는다.

완료 조건:

- 팀원이 하드웨어 관련 업무의 진입점을 `/admin/hardware`에서 찾을 수 있다.
- 기존 `/admin/quotes`, `/admin/crm`, `/admin/hw-sales`, `/admin/install-schedules`는 깨지지 않는다.

### Phase 2. 견적/문서 통합

- `QuickQuoteComposer`를 어드민 하드웨어 견적/문서 탭에서 사용할 수 있게 한다.
- 고객/딜 선택을 어드민 권한으로 동작하게 검증한다.
- 저장, 미리보기, 공유 링크 생성, 링크 복사, 문자/카카오톡 공유를 어드민에서 제공한다.
- 발송 상태와 열람/동의 상태를 같은 목록에서 보여준다.

완료 조건:

- 어드민에서 견적 작성 후 공개 견적 링크를 생성할 수 있다.
- 고객에게 보낼 수 있는 링크가 생성된다.
- 기존 공개 견적 페이지가 그대로 열람된다.

### Phase 3. 영업 파이프라인 통합

- 하드웨어 리드, 고객, 딜을 한 목록에서 본다.
- 딜 상세에서 견적/계약/설치/재고 상태를 함께 보여준다.
- 다음 액션, 연락 로그, 담당자를 하드웨어 흐름에 맞춰 노출한다.

완료 조건:

- 리드에서 견적까지 같은 하드웨어 탭 안에서 이어진다.
- 견적 상태가 딜 단계에 반영된다.

### Phase 4. 재고/설치 연결

- 견적 품목과 하드웨어 SKU를 연결한다.
- 계약 전환 시 예약 재고를 만든다.
- 설치 일정과 예약 재고를 연결한다.
- 설치 완료 시 출고/완료 상태를 반영한다.

완료 조건:

- 견적 품목이 재고 예약으로 이어진다.
- 설치 예정 물량과 남은 재고를 하드웨어 탭에서 확인할 수 있다.

### Phase 5. 기존 탭 정리

- 사용성이 검증된 뒤 기존 탭을 숨기거나 하드웨어 탭으로 리다이렉트한다.
- `/admin/quotes`는 `/admin/hardware?tab=quotes` 안내 또는 리다이렉트 후보로 둔다.
- 독립 문서/계약/영수증 탭은 범용 문서 관리가 필요하면 유지한다.

완료 조건:

- 어드민 최상위 탭이 불필요하게 늘어나지 않는다.
- 하드웨어 업무는 하드웨어 탭에서 시작하고 끝난다.

## 7. 구현 시 유지할 것

- 기존 디자인 톤과 컴포넌트 스타일
- 기존 견적 템플릿 작성 경험
- 공개 견적 링크 페이지
- 견적 버전 관리
- 공유 링크 생성
- 고객 열람/동의 추적
- 계약 전환 흐름

## 8. 구현 시 피할 것

- 파트너 포탈 기능을 한 번에 삭제
- 견적 데이터 모델을 더 늘리는 것
- 어드민 최상위 탭을 계속 추가
- 재고와 견적을 분리된 화면에서 따로 관리
- 공개 링크 없이 내부 화면 캡처나 PDF만으로 발송 처리

## 9. 남은 결정사항

- 이메일 발송을 실제 SMTP/Resend 기반으로 붙일지, 우선 링크 공유로 둘지
- `quotes / quote_items`를 언제 `quote_documents` 계열로 마이그레이션할지
- 하드웨어 재고의 기준 단위를 SKU, 시리얼, 설치 세트 중 무엇으로 잡을지
- 파트너가 제출해야 하는 정보의 최소 폼 범위
- 기존 파트너 포탈 메뉴를 숨길 시점

## 10. 추천 우선순위

1. `/admin/hardware` 허브 생성
2. 견적/문서 탭에 `QuickQuoteComposer` 통합
3. 공개 견적 링크 생성과 공유 시트 유지
4. 하드웨어 영업 파이프라인 연결
5. 견적 품목과 재고 SKU 연결
6. 설치 일정/예약 재고 연결
7. 기존 탭 정리
