# 화면에 중국어가 그대로 보인다

## 증상 표현

| 고객 표현 | 실제 현상 | 선례 |
|---|---|---|
| "녹화 수업 AI 요약·스크립트가 중국어로 나온다" | 한국어 음성 녹화 수업(동영상 업로드형)의 AI 요약·스크립트가 중국어로 생성, 일부는 주제도 영상과 무관 | D-11 |
| "학생 휴대폰에서 트로피 문구가 중국어" | 리본 문구가 중국어판(`恭喜你获得一次奖励！`), 같은 화면 토스트는 한국어 — 사양상 영문판이 나와야 함(缺陷) | S-28 |
| "교실 에이전트 목록이 중국어" | 한국어 환경에서 `瓦力` / `素材搜索` / `函数图像`이 그대로 노출(6.0.9) | T-01 |
| "AI 리스크 분석 결과가 중국어" | 콘솔은 한국어인데 수업 상세 "AI 분석" 항목이 전부 중국어(전사는 한국어). 번역 키 노출, 중국어 배너 등 동반 | T-02 |
| "수업 분석 보고서 아래에 중국어 문구" | 보고서 하단 중국어 고지문 2줄이 한국어 환경·PDF에 노출, 에이전트 기본값이 중국어명 | T-03 |
| "새 관리자 대시보드가 이상한 말로 나온다" | 브라우저 내장 자동 번역이 켜져 번역된 UI가 틀리게 표시 | S-04 |
| "콘솔 API 메뉴가 중국어" | API 연동 페이지가 언어 전환 불가 | T-04 |

증상 동의어: 중국어 나옴, 중국어 표시, 한국어 안 나옴, 번역 안 됨, 현지화 누락, 한글화, AI 요약 중국어, 스크립트 중국어, 트로피 중국어, 번역 키 노출, 영어·중국어 섞임, 자동 번역 깨짐

## 먼저 받을 값

1. 같은 기관, 같은 기기의 화면 캡처(다른 기관·다른 기기 캡처는 증거로 쓸 수 없다)(S-28).
2. 앱 언어, 시스템 언어, 클라이언트 버전, 기기·OS.
3. AI 출력이면: 수업 구분(라이브 녹화인지 동영상 업로드형 녹화 수업인지), 수업명, 생성 날짜(D-11).
4. 웹 콘솔이면: 브라우저 종류, 자동 번역 설정 상태(S-04).
5. 기관 측 관련 설정(예: 트로피 설정)(S-28).

## 진단 흐름

1. 이 문서의 선례(인덱스 12장 계열: T-01, T-02, T-03, S-28)와 D-11에서 이미 알려진 건인지 본다.
2. **버그(잘못된 판이 나옴)와 기능 요청(한국어판이 없음)을 나눠서** 보고한다. 섞으면 제안(`建议`)으로 내려간다(S-28).
3. 증거는 같은 기관, 같은 기기의 화면이어야 한다. 앱 언어, 시스템 언어, 버전을 같이 적는다.
4. UI 문자열은 Crowdin, AI가 생성한 내용이 중국어로 나오는 것은 제품 로직 쪽(HQ AI 교실·AI 녹화 제품 담당)으로 간다.

선례별 세부

- **AI 요약 중국어(D-11)**: "한국어 요약은 2026년 3월부터 지원"이라는 HQ 회신이 있어 2월 생성분을 미지원 시기 생성분으로 정리했지만, 2025-04에 생성된 정상 건이 있어 시기 한정으로 단정하지 않는다. 재요약 신청은 课节id 또는 机构ID + 班级名 + 课节名으로 하고, 「동영상 업로드형」임을 매번 명시한다. 재요약 신청은 가능했다(녹화 복구와는 별개).
- **트로피(S-28)**: 콘솔 奖杯设置 사양상 ClassIn 언어가 중국어면 중문판, 그 외는 영문판이다. 토스트가 한국어이므로 영문판이 나와야 한다 → 缺陷. 한국어판 트로피는 자산이 없어 별도 需求. 제출 전 보완 증거: 모바일 OS·앱 버전, 앱/시스템 언어, 기관 트로피 설정, 교사 PC 화면, 영어 전환 재현, 타 고객 발생 여부.
- **신버전 직후(T-01)**: 신버전이 나온 직후의 이상은 같은 현장 다른 기기의 버전과 대조한다. 실시간 자막 번역 "연결 실패"는 회선이 '아주 나쁨'인 상태에서 나 서비스 결함과 구분되지 않았다.
- **AI 리스크 모니터링(T-02)**: 항목별로 현지화·서버 사이드·사양이 섞여 있다. 번역 키 노출·SMS 템플릿 언어 혼합·중국어 배너는 현지화(Crowdin "KR revision" 시트), AI 분석 중국어는 현지화인지 서버 사이드인지 미구분.
- **AgentIn 보고서(T-03)**: 템플릿이 안 보이면 좌측 'ClassIn' 대신 '모두' > '수업 분석' 경로로 선택한다(카테고리 필터 차이).
- **대시보드 자동 번역(S-04)**: OS·브라우저가 달라도 같은 증상이면 페이지 측 문제로 보고하고, 비교 이미지와 재현 계정을 같이 준다.
- **콘솔 API 메뉴(T-04)**: 영문 공식 문서(docs.eeo.cn/api/en/)를 안내한다(`10-api.md`).

## 고객 안내 문구

결과 회신 뼈대(카카오톡):

```
안녕하세요, ○○님. 화면 표시 언어 건 확인 결과입니다.

▪ 확인된 내용
(확인된 사실. 본사 확인 중이면 그 범위까지만)

▪ 지금 하실 수 있는 것
(우회 경로나 설정. 예: 브라우저 자동 번역 끄기, 재요약 신청 접수)

▪ 다시 발생하면
(알려 달라는 정보: 화면 캡처, 앱 언어·버전)
```

쓸 때 지킬 것

- HQ가 확답하지 않은 지원 일정·사양(예: 언어 지원 시작 시기)은 단정해 전하지 않는다.
- WeCom 자동 번역 결과를 그대로 옮기지 않는다.
- HQ가 준 중국어 UI 캡처는 그대로 보내지 않고 한국어 화면으로 다시 찍어 주석을 단다.
- 결함 단정은 하지 않는다. 확인된 범위(어느 화면, 어느 버전)까지만 쓴다.
- 내부 테스트 계정 정보, 번역 시트 이름 같은 내부 정보는 넣지 않는다.

## HQ로 넘기는 조건과 적을 것

넘기는 조건

- 같은 기관·같은 기기 증거와 언어·버전 정보를 갖춘 뒤.
- 버그(잘못된 판)는 `缺陷`, 한국어판 부재는 `需求`로 따로 보낸다(S-28).
- 브라우저 자동 번역처럼 환경 문제로 판명되면 넘기지 않는다(S-04는 HQ 결론 없이 대기).

받는 곳(역할명)

- AI 생성 내용(요약, 스크립트, AI 분석): HQ AI 교실·AI 녹화 제품 담당. 라우팅은 HQ 하드웨어 총괄·OPS 이미지 담당을 거친 선례가 있다(D-11).
- AgentIn: HQ LMS·AgentIn 담당, AgentIn 활성화 요청은 HQ AI 교실·AI 녹화 제품 담당
- AI 리스크 모니터링 SMS: HQ SMS 담당
- UI 문자열: Crowdin(현지화) 경로
- 1차: HQ 서비스 1차 접점(小助手)
- 지사 계정은 TAPD 읽기 전용이라 등록은 HQ에 대리 요청한다.

적을 것

- 분류(`缺陷` / `需求`)를 맨 앞에. 섞지 않는다.
- 같은 기관·같은 기기 화면, 앱 언어, 시스템 언어, 클라이언트 버전, 기기·OS.
- AI 출력은 수업 구분(동영상 업로드형 등), 생성 날짜, 재요약 신청 키(课节id 또는 机构ID + 班级名 + 课节名).
- 시각은 중국 시각(UTC+8 = KST − 1시간).

기재하지 않는 값과 예외

- 기재하지 않는 값: Device ID, Client IP, Server, Owner.
- 조회 키(课节ID, 기관 ID)와 사내 테스트 계정은 WeCom 발송문에만 넣고 이 저장소·적재 데이터에는 남기지 않는다.
