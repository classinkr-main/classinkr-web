## 챗봇 반영 원칙

이번 업데이트는 원본 합성 캡처를 공개 문서 자산으로 복사하지 않고, 개인정보가 없는 단계형 텍스트만 추가했다.

- 앱 다운로드 질문은 기기별 설치 가이드로 바로 연결한다.
- 회원가입 절차 질문은 신규 가이드로 답하되, 필요한 개인정보나 가입 정책 질문은 기존 도입 전 FAQ 흐름을 유지한다.
- 계정 삭제는 복구가 어려운 작업임을 먼저 확인하도록 안내한다.
- 편입생 등록, 코스 구성원, 채팅 제어, 코스 생성·종료는 명시적인 절차 질문에만 직접 답한다.
- 시험 문제 업로드와 숙제 제출은 기존 검증된 답변을 재사용한다.
- 원본 파일명, 고객명, 연락처, 계정 식별자, 캡처 출처 표현은 소비자 답변에 노출하지 않는다.
