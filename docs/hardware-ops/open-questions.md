# Hardware Ops Open Questions

기준 시점: 2026-04-06  
관련 문서: [README](./README.md), [운영 건 상세](./operation-case-workspace.md)

## 1. 제품/IA 질문

- 메뉴 이름을 계속 `파트너 운영`으로 둘지, `하드웨어 운영`으로 바꿀지
- 리스트 1차 진입 기준을 `고객사 목록`으로 둘지, `운영 건 큐`로 둘지
- 현재 `/admin/partners` 라우트를 장기적으로 유지할지

## 2. 데이터 모델 질문

- 고객사와 기존 클래스인 고객 데이터를 어느 키로 연결할지
- 총판이 사실상 단일 축일 때 별도 엔티티를 얼마나 전면에 둘지
- 운영 건과 기존 거래/deal 개념을 어떻게 구분할지

## 3. 문서 운영 질문

- 계약서 원본/발송본/체결본 UI를 한 카드에서 볼지 분리할지
- 카카오 공유, 보호 링크, PDF 첨부를 어떤 공통 모델로 묶을지
- 열람/다운로드 이력을 상세 어디까지 보여줄지
- 견적서 `estimateNumber` 발번 규칙을 어떻게 둘지
- `기타사항`과 `특약사항`의 템플릿/자유입력 경계를 어디까지 둘지
- `별도 청구 예정` 같은 비가격 행을 `billingMode`와 `lineStatus` 중 어디에 더 강하게 걸지
- VAT 포함/별도 문서를 같은 템플릿에서 처리할지, 템플릿을 분리할지
- 견적서 accepted 기준을 열람 이후 수동 처리로 볼지, 별도 승인 상태로 둘지

## 4. 수량 운영 질문

- 품목 마스터를 둘지, 운영 건별 자유 입력을 먼저 허용할지
- 수량 불일치를 어느 시점부터 이슈로 자동 승격할지
- 설치 완료 수량과 정산 수량이 다를 때 어떤 상태를 기본으로 볼지

## 5. 권한/협업 질문

- 본사 전용 메모와 총판 공유 메모를 어떻게 분리할지
- 이슈의 공개 범위를 항목마다 둘지, 탭 전체 정책으로 둘지
- 문서 링크와 보안 설정 편집 권한을 누구에게 줄지

## 6. 다음 대화에서 바로 정하면 좋은 것

3. 문서 탭 row 단위 모델 확정
4. 수량 탭 row 단위 모델과 불일치 규칙 확정
