## 1. 설계 목표

파트너 포털은 단순 문서 열람 화면이 아니라 `거래 흐름을 따라 운영 판단을 내리는 보드`여야 한다.
따라서 화면은 아래 원칙을 따른다.

- 기관보다 `거래건`이 실제 운영 중심이다
- 탭은 보기 단위일 뿐, 상태 전환은 한 흐름으로 이어져야 한다
- 문서 / 설치 / 수납 / 로그는 각기 분리되지만 거래건 안에서 다시 합쳐져 보여야 한다
- 시각적으로는 미니멀하지만, 단계와 후속 액션이 보이는 `게임 UI형 운영판` 톤을 유지한다

## 2. 공통 UI 원칙

### A. 공통 화면 골격

- 상단: 화면 제목, 현재 문맥, 주요 CTA
- 중단 상부: 요약 카드 또는 단계 로드맵
- 중단 본문: 2~3열 보드, 리스트, 타임라인 조합
- 우측 또는 하단: 후속 액션, 경고, 활동 로그

### B. 공통 시각 패턴

- `단계 로드맵 바`: 컨택 → 견적 → 계약 → 확정 → 설치 → 수납
- `카드 스택`: 기관 아래 여러 거래건이 겹쳐 보이는 구조
- `미니 스탯 바`: 문서 / 설치 / 수납 상태를 작은 막대나 점으로 표현
- `타임라인`: 활동 로그, 설치 일정, 수납 이벤트의 시간 흐름 표현
- `알림 레일`: 서명 대기, 일정 충돌, 미수금 경고를 우측 패널에 고정

### C. 탭 설계 원칙

- 거래건 상세만 탭 중심 구조를 강하게 사용한다
- 문서함 / 설치 / 수납은 탭보다 `보기 전환`이 더 적합하다
- 모든 탭은 “조회”와 “다음 액션”이 함께 있어야 한다

## 4. 홈 화면

### 화면 목적

- 오늘 해야 할 일과 병목을 한눈에 보여주는 운영판
- 거래 흐름 전체를 단계별로 보고 바로 다음 액션으로 이동시키는 허브

### 레이아웃 블록

#### 1. 상단 헤더

- 화면 제목: `홈`
- 보조 문구: 오늘 기준 운영 현황
- 우측 CTA:
  - 새 거래건 추가
  - 새 일정 추가
  - 문서 발송 대기 보기

#### 2. Top Summary Strip

- 진행 중 견적 수
- 진행 중 계약 수
- 설치 예정 건수
- 설치 진행 중 건수
- 총 판매 대수
- 미수금
- 미수 기관 수

#### 3. 메인 보드 3열

- 좌측: `기관별 거래 스택`
- 중앙: `단계 로드맵 보드`
- 우측: `오늘 일정 / 경고 / 서명 대기`

### 탭 구성

- 별도 탭 없음
- 대신 상단 필터 칩 제공
  - 전체
  - 내 주의 필요
  - 설치 임박
  - 수납 지연

### 블록별 핵심 콘텐츠

#### 기관별 거래 스택

- 기관명, 담당자, 지역
- 활성 거래건 수
- 최근 거래 단계
- 기관 단위 미수 여부
- 기관 아래 서브 카드로 추가 계약건 표시

#### 단계 로드맵 보드

- 단계별 컬럼: 컨택 / 견적 / 계약 / 확정 / 설치 / 수납
- 각 거래 카드에 표시:
  - 기관명
  - 거래명
  - 예상 금액
  - 최근 문서 상태
  - 설치 일정 존재 여부
  - 수납 상태 점등

#### 오늘 일정 / 경고

- 오늘 설치
- 오늘 미팅
- 서명 대기 계약
- 미수금 경고 거래
- 일정 충돌 또는 미배정 설치팀

### 핵심 컴포넌트

- KPI 스트립 카드
- 단계 노드 + 연결선 로드맵
- 거래건 칸반 카드
- 경고 배지
- 우선순위 액션 리스트

## 5. 기관 상세 화면

### 화면 목적

- 기관 자체를 관리하기보다, 해당 기관에 연결된 거래건을 빠르게 탐색하는 입구
- 해당 기관의 `거래 이력과 세부 내역`을 한 번에 확인하는 고객 상세 화면

### 레이아웃 블록

#### 1. 헤더

- 기관명
- 담당자 / 연락처
- 주소 / 사업자번호
- 선택 메타: 관 / 캠퍼스 / 지역
- 우측 CTA:
  - 새 거래건 추가
  - 고객 정보 수정
  - 미팅 로그 추가

#### 2. Summary Row

- 진행 거래건 수
- 총 계약 금액
- 총 설치 완료 금액
- 실수납 누계
- 미수금

#### 3. 본문 2열

- 좌측 메인:
  - 활성 거래건
  - 완료 거래건
- 우측 보조:
  - 최근 문서
  - 최근 설치 일정
  - 최근 활동 로그

### 탭 구성

- `개요`
- `거래건`
- `활동`

### 탭별 콘텐츠

#### 개요

- 기관 기본 정보
- 요약 수치
- 최근 문서 3건
- 최근 설치 일정 3건
- 최근 수납 상태 요약

#### 거래건

- 활성 거래건 리스트
- 완료 거래건 접이식 리스트
- 각 카드에 현재 단계, 금액, 최근 액션, 다음 액션 노출
- 추가 계약이나 다른 관/지역 계약도 별도 카드로 분리해서 이력처럼 보이게 구성
- 정렬 기본값은 `최근 수정 순`, 보조 필터는 `진행 중 / 완료 / 취소 / 미수 있음`

#### 활동

- 기관 단위 미팅 로그
- 고객 정보 변경 로그
- 기관과 연결된 거래건들의 최근 활동 묶음

#### 기관 상세 보조 섹션

- `거래 이력 표/리스트`
  - 거래명
  - 단계
  - 계약 금액
  - 설치 완료 금액
  - 실수납
  - 미수금
  - 최근 활동 시각
- `최근 거래 흐름`
  - 계약 발송
  - 서명
  - 설치 일정 확정
  - 수납 등록

### 핵심 컴포넌트

- 기관 프로필 카드
- 거래건 스택 카드
- 최근 활동 타임라인
- 요약 숫자 카드

## 6. 거래건 상세 화면

### 화면 목적

- 파트너 포털의 핵심 화면
- 문서, 설치, 수납, 로그를 하나의 거래 흐름 안에서 연결

### 레이아웃 블록

#### 1. 상단 고정 헤더

- 거래건 제목
- 기관명
- 현재 단계
- 거래 금액
- 최근 수정 시각
- 담당자 / 설치 담당
- 우측 CTA:
  - 다음 단계 진행
  - 문서 생성
  - 일정 생성
  - 수납 등록

#### 2. 단계 로드맵 바

- 컨택 → 견적 → 계약 → 확정 → 설치 → 수납
- 현재 단계 강조
- 완료 단계는 채움 처리
- 다음 단계는 CTA 버튼 노출
- 각 단계 아래 최소 상태:
  - 문서 존재 여부
  - 설치 일정 존재 여부
  - 수납 상태

#### 3. 본문 탭 영역

- 상단 탭
- 본문 콘텐츠
- 우측 서브 패널: 다음 액션 / 경고 / 최근 로그

### 탭 구성

- `개요`
- `문서`
- `설치`
- `수납`
- `활동`

### 탭별 콘텐츠

#### 개요

- 현재 상태 카드
- 금액 요약
- 판매 품목 요약
- 다음 액션 추천
- 최근 문서 / 최근 일정 / 최근 수납 미리보기
- 현재 병목 사유

#### 문서

- 견적서 섹션
- 계약서 섹션
- 각 문서별 최신 버전 카드
- 이전 버전 아코디언
- 발송 링크 복사
- PDF 다운로드
- `shared` 배지로 고객 공개 버전 표시

문서 탭의 핵심 원칙:

- 고객 링크는 항상 버전 고정
- 관리자/파트너는 최신 버전과 이전 버전 모두 열람 가능
- 새 버전 저장과 고객 발송 버전 지정은 분리

#### 설치

- 일정 리스트
- 타임라인
- 미니 캘린더
- 복수 일정 허용

각 일정 카드 정보:

- 시작 / 종료 시각
- 장소
- 설치 팀
- 상태
- 메모

설치 탭 주요 액션:

- 일정 추가
- 일정 수정
- 일정 확정
- 설치 완료 처리

#### 수납

- 계약 금액
- 실수납 누계
- 미수금
- 수납 상태

하단 콘텐츠:

- 입금 기록 리스트
- 영수증 발행 기록
- 예정 수납 메모

수납 상태는 아래 3단으로 시작:

- 미수
- 부분 수납
- 수납 완료

#### 활동

- 미팅 로그
- 문서 로그
- 단계 변경 로그
- 설치 로그
- 수납 로그

표보다 `접을 수 있는 타임라인`이 적합하다.

### 핵심 컴포넌트

- 거래 단계 로드맵
- 다음 액션 CTA 바
- 문서 버전 카드 + 아코디언
- 설치 일정 카드
- 수납 누계 카드
- 통합 활동 타임라인

## 7. 문서함 화면

### 화면 목적

- 모든 견적서 / 계약서를 거래건과 함께 검색하고, 버전과 발송 상태를 관리하는 허브

### 레이아웃 블록

#### 1. 헤더

- 화면 제목: `문서함`
- 우측 CTA:
  - 새 견적서
  - 새 계약서
  - PDF 생성

#### 2. 상단 필터 바

- 문서 종류
- 상태
- 공유 여부
- 기관명 검색
- 거래건 검색
- 최근 수정일 정렬

#### 3. 본문 2분할

- 좌측: 문서 리스트
- 우측: 선택 문서 상세 / 버전 패널 / 프리뷰

### 탭 구성

- `전체`
- `견적서`
- `계약서`
- `공유됨`
- `초안`

### 탭별 콘텐츠

#### 전체

- 모든 문서 통합 리스트
- 거래건, 기관, 버전, 상태, 공유 여부를 한 줄에서 확인

#### 견적서

- 최신 견적 버전 우선
- 이전 버전 접기
- 견적 발송 여부, 유효기간 표시

#### 계약서

- 서명 상태 중심
- 서명 대기 / 대표 서명 완료 / 완료 분리

#### 공유됨

- 고객에게 발송된 버전만 필터링
- 링크 복사 / 마지막 발송일 / 발송 버전 표시

#### 초안

- 아직 고객에게 나가지 않은 문서
- 작성 중 / 검토 필요 / 발송 전 체크리스트 표시

### 핵심 컴포넌트

- 문서 리스트 행 카드
- 버전 히스토리 아코디언
- 사이드 패널 편집기
- 실시간 프리뷰 패널
- 공유 링크 상태 배지

## 8. 설치 캘린더 화면

### 화면 목적

- 설치를 중심으로 미팅, 문서 마감, 내부 일정을 함께 보는 공용 이벤트 레이어

### 레이아웃 블록

#### 1. 헤더

- 화면 제목: `설치 캘린더`
- 기간 전환: 월 / 주 / 리스트
- 우측 CTA:
  - 일정 추가
  - 팀 배정
  - 충돌 보기

#### 2. 상단 상태 바

- 이번 주 설치 예정 건수
- 확정 대기 건수
- 진행 중 건수
- 완료 건수
- 일정 충돌 수

#### 3. 본문

- 좌측 메인: 캘린더
- 우측 패널:
  - 선택 날짜 일정
  - 다가오는 설치
  - 미배정 일정

### 탭/보기 구성

- `캘린더`
- `보드`
- `리스트`

### 보기별 콘텐츠

#### 캘린더

- 월 / 주 기준 설치 일정
- 미팅 / 문서 마감 / 내부 일정 오버레이
- 일정 클릭 시 거래건 상세와 연결

#### 보드

- 상태 컬럼: 예정 / 확정 / 진행 중 / 완료 / 보류
- 설치 카드 단위로 팀 배정, 일정 변경, 완료 처리

#### 리스트

- 시간 / 장소 / 기관 / 거래건 / 설치 팀 기준 정렬
- 다건 설치, 분산 설치, 반나절 일정을 한눈에 확인

### 핵심 컴포넌트

- 공용 이벤트 캘린더
- 설치 상태 보드 카드
- 일정 충돌 배지
- 팀 배정 패널
- 선택 날짜 상세 패널

## 9. 수납 화면

### 화면 목적

- 거래별 수납 현황과 미수 리스크를 빠르게 관리하는 관제판
- 단건 영수증 목록이 아니라 `누계와 미수금` 중심으로 본다

### 레이아웃 블록

#### 1. 헤더

- 화면 제목: `수납`
- 우측 CTA:
  - 입금 등록
  - 영수증 발행
  - 미수 거래 보기

#### 2. 상단 KPI 바

- 총 계약 금액
- 총 실수납 누계
- 총 미수금
- 부분 수납 거래 수
- 미수 기관 수

#### 3. 본문 2열

- 좌측: 거래별 수납 리스트
- 우측:
  - 선택 거래 수납 상세
  - 영수증 기록
  - 예정 수납 메모

### 탭 구성

- `전체`
- `미수`
- `부분 수납`
- `수납 완료`
- `영수증`

### 탭별 콘텐츠

#### 전체

- 모든 거래건의 계약 금액, 수납 누계, 미수금, 마지막 입금일 표시

#### 미수

- 아직 입금이 없는 거래
- 설치 완료 후 미수인 건 우선 정렬

#### 부분 수납

- 분할 입금 진행 중인 거래
- 다음 예정 입금 메모 또는 약속일 표시

#### 수납 완료

- 완납된 거래
- 영수증 최종 발행 상태 포함

#### 영수증

- 영수증 번호
- 발행일
- 연결 거래건
- 금액
- PDF 다운로드

### 핵심 컴포넌트

- 수납 누계 카드
- 미수 위험 리스트
- 입금 기록 타임라인
- 영수증 리스트
- 상태 배지: 미수 / 부분 수납 / 완료

## 10. 화면 간 흐름 연결

### 홈 → 거래건 상세

- 칸반 카드 클릭으로 이동
- 카드에서 바로 `다음 단계 진행` 가능

### 기관 상세 → 거래건 상세

- 활성 거래건 카드 중심 이동
- 기관 화면은 탐색기, 액션은 거래 화면에서 처리

### 거래건 상세 → 문서함 / 설치 캘린더 / 수납

- 탭에서 처리 가능하되, 더 넓은 검색/관리 필요 시 각 전용 화면으로 연결
- 전용 화면에서도 항상 원 거래건으로 되돌아올 수 있어야 한다

## 11. 시각 언어 요약

- 배경: 웜 화이트 / 라이트 스톤
- 카드: 화이트
- 선: 연한 그레이
- 강조: 차콜
- 상태색:
  - 블루: 진행
  - 그린: 완료
  - 옐로: 주의
  - 레드: 리스크

게임 UI 느낌은 아래 정도로 제한한다.

- 단계 노드와 연결선이 분명하다
- 카드 안의 미니 상태 막대가 흐름을 보여준다
- 숫자와 배지가 빠르게 읽힌다

피해야 할 방향:

- 진한 네온 컬러
- 장식성 아이콘 과다
- 테이블만 가득한 ERP 톤
