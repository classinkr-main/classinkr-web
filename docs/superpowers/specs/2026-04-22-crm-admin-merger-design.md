# CRM + 어드민 파트너 포털 합병 — 설계 스펙

작성일: 2026-04-22
브랜치: `crm_v0`
상태: 승인됨

---

## 1. 배경 및 목표

### 현황 문제
- `/admin/partners` — 총판/파트너 중심 워크스페이스로 설계됨
- `/partner/*` — 외부 파트너가 사용하는 포털로 설계됐으나 실제로 사용하지 않음
- 두 시스템이 분리되어 데이터와 UI가 중복·분산됨

### 개편 목표
- **사용자:** 내부 팀원(지사) + 지사장 + 파트너(총판) 1명 — 외부 파트너 포털 없음
- **중심 단위:** 고객사(학교/기관) 중심의 CRM + HW 운영 통합 허브
- **파트너 포털:** 어드민에 병합, 향후 분리 가능한 구조로 열어두기

### 핵심 사용 시나리오
팀원이 고객사 방문 후 → 미팅 로그 기록 → 견적서 발행 → 설치 체크리스트 업데이트를 **하나의 고객사 워크스페이스**에서 처리

## 2. 사용자 및 권한

| 역할 | 설명 | 권한 |
|------|------|------|
| 팀원 | 한국 지사 내부 팀원 | 전체 읽기/쓰기 |
| 지사장 | 팀원 + 추가 관리 권한 | 전체 + 삭제·정산 확정 |
| 파트너(총판) | HW 담당 1명 | 어드민 계정으로 접근 (현재) |

## 4. CRM 섹션

### 4-1. 리드 (`/admin/crm/leads`)

**목적:** 신규 문의부터 고객사 전환까지의 영업 파이프라인 관리

**상단 요약 바**
- 신규 리드 수
- 상담 진행 중
- 견적 발송 대기
- 이번 주 전환 수

**뷰 전환:** 카드(칸반) | 테이블

**리드 카드 정보**
- 기관명 / 담당자
- 문의 채널 (홈페이지·직접·파트너)
- 현재 상태: `신규 → 상담중 → 견적중 → 전환 → 이탈`
- 담당 팀원
- 다음 액션 일시

**핵심 액션**
- `고객사로 전환` → 고객사 워크스페이스 자동 생성
- `이탈 처리` → 사유 기록 후 아카이브

---

### 4-2. 고객사 목록 (`/admin/crm/customers`)

**목적:** 전환된 고객사 목록 및 운영 상태 큐

**상단 요약**
- 활성 고객사 수
- 이번 달 신규 전환
- 계약 갱신 임박
- 미해결 이슈

**리스트 컬럼**
- 기관명
- 담당 팀원
- 현재 딜 단계
- 다음 액션 일시
- 미완료 체크 수
- 미해결 이슈 수

---

### 4-3. 고객사 워크스페이스 탭 7개

`/admin/crm/customers/[id]` — 고객사 하나에 모든 정보가 집결

#### 탭 1: Overview

- 상태 카드 6개: 현재 딜 단계 / 오늘 할 일 / 미완료 이슈 / 확인 필요 문서 / 누적 판매 / 누적 순매출
- 실행 큐: 예정 일정 + 확인 필요 문서 (상위 4개)
- 최근 맥락: 최근 미팅 로그 3~4개
- 판단 필요 이슈: critical/high 우선 표시

#### 탭 2: 파이프라인

- 딜 목록 + 단계별 배지 (`발굴 → 견적 준비 → 계약 발송 → 진행중 → 성사 → 종료`)
- 딜별 다음 단계 CTA 자동 제안 (단계에 따라 `계약 생성`, `체크리스트 생성`, `판매 기록 추가` 등)
- 판매 실적 (월별 판매 댓수 / 총액 / 순매출)

#### 탭 3: 문서

- 견적서 / 계약서 / 영수증 CRUD
- 문서별 상태: `초안 → 발송됨 → 서명완료 → 정산완료 → 연체 → 보관`
- 전달 이력: PDF · 링크 · 카카오
- 접근 정책: 만료일 / 비밀번호 / 다운로드·인쇄 허용
- 우선순위 패널: 연체·만료·전달 이력 없음 문서 상단 노출
- **어드민 빠른 실행 "새 견적"과 동일한 폼 공유**

#### 탭 4: 미팅·로그

- 미팅 / 전화 / 카카오 / 이메일 / 내부 메모 기록
- 타임라인 뷰 (최신순)
- 로그별 다음 액션 연결
- 로그 상태: `recorded → follow_up_needed → waiting_partner → waiting_internal → blocked → resolved`

#### 탭 5: HW 이행

- 설치 품목·수량 체크리스트
- 이행 상태: `계획 → 발주 → 입고 → 설치 → 검수 → 이슈`
- Todo 상태: `open → waiting_partner → waiting_internal → blocked → done`
- 수량 불일치 자동 감지 + 배지
- 우선 처리 패널: 차단·수량 불일치·마감 임박 항목

#### 탭 6: 연락처

- 담당자 목록 (대표·실무 구분)
- 이름 / 직책 / 이메일 / 전화번호
- 대표 연락처 지정

#### 탭 7: 이슈

- 판단 필요 이슈 카드
- 필드: 제목 / 분류 / 심각도 / 상태 / 담당자 / 마감 / 사실·미해결포인트·현재가정
- 심각도: `critical → high → medium → low`
- 상태: `open → waiting → blocked → resolved`
- 연결: 딜 / 문서 / 체크리스트

## 5. HW 운영 섹션 (`/admin/hw`)

**목적:** 고객사를 횡단하는 전체 설치 현황 한눈에 보기 (총판 주 사용)

**상단 요약**
- 전체 진행 중 설치 건수
- 수량 불일치 건수
- 이번 주 설치 마감
- 검수 대기

**이행 테이블 (필터: 고객사 | 담당자 | 이행 상태 | 마감일)**

| 고객사명 | 품목 | 계획 수량 | 확정 수량 | 이행 상태 | 담당자 | 마감일 |
|---------|------|---------|---------|---------|------|------|

- 행 클릭 → 해당 고객사 HW 이행 탭으로 이동

---

## 6. 어드민 사이드바 빠른 실행

사이드바 하단 고정. 고객사 선택 → 해당 탭 폼 바로 오픈.

| 액션 | 연결 |
|------|------|
| ＋ 새 견적 | 고객사 선택 → 문서 탭 견적 폼 |
| ＋ 미팅 로그 | 고객사 선택 → 미팅·로그 탭 폼 |
| ＋ 이슈 등록 | 고객사 선택 → 이슈 탭 폼 |
| ＋ 리드 추가 | 리드 생성 폼 직접 오픈 |

## 7. 기존 코드와의 관계

| 기존 | 신규 | 처리 |
|------|------|------|
| `/admin/partners` | `/admin/crm/customers` | 리네이밍 + 기능 확장 |
| `/admin/partners/[id]` | `/admin/crm/customers/[id]` | 탭 재구성 (7탭) |
| `/partner/*` | 어드민 병합 | 라우트 제거, 기능 흡수 |
| `PartnerWorkspaceShell` | `CustomerWorkspaceShell` | 리네이밍 + 탭 재구성 |
| `/api/admin/partners/*` | `/api/admin/customers/*` | 엔드포인트 마이그레이션 |
| `/api/portal/*` | `/api/admin/customers/*` 통합 | 병합 후 portal 라우트 제거 |

## 8. 데이터 모델 변경 요점

- `partner_accounts` → `customers` (고객사 테이블)
- `partner_workspace` 구조 유지, `customer_id` 기준으로 재매핑
- 리드 테이블: 기존 `contacts`/`leads` 테이블 활용 or 신규 `crm_leads`
- 권한: `role` 컬럼 (`member` / `branch_manager`) — 현재 `admin_profiles` 확장

---

## 9. 구현 우선순위 (Phase)

### Phase 1 — 구조 전환
- 사이드바 네비게이션 재구성
- `/admin/partners` → `/admin/crm/customers` 리네이밍
- 고객사 워크스페이스 7탭 재구성 (기존 6탭 기반)

### Phase 2 — CRM 리드
- 리드 섹션 신규 구현
- 리드 → 고객사 전환 플로우
- 빠른 실행 4개

### Phase 3 — HW 운영 횡단 뷰
- `/admin/hw` 전체 이행 현황 테이블
- 필터·정렬·클릭 연결

### Phase 4 — 정리
- `/partner/*` 라우트 제거
- `/api/portal/*` 통합 또는 제거
- 파트너(총판) 계정 설정 이동

- 파트너(총판) 계정이 나중에 분리될 때 라우트/권한 분리 기준
- 캘린더: 고객사 일정과 팀 일정 통합 방식
