# 녹화 · AI 리포트 딥다이브 랜딩 — 설계

- 작성일: 2026-08-28
- 상태: 승인됨 (구성안 합의 후 작성)
- 파트: 홈 및 랜딩 (home-front)

## 목적

SW·HW 제품 탭에서 버튼으로 진입하는 **기능 딥다이브 랜딩**. 녹화와 AI 리포트(녹화
수업 → 음성인식 → 리포트 자동 작성)를 심도 있게 설명하고 설득한다. 사이트 최초의
기능 딥다이브 페이지다.

## 확정 사항

| 항목 | 결정 |
| --- | --- |

| 타깃 | 학원 원장, 실장 (구매 결정자) |

## 5섹션 구성 (여정축)

1. **히어로 — 문제 제기**: "수업이 끝나면, 그 수업이 어땠는지 아무도 모릅니다."
   원장 고충 3줄(강사 수업을 다 못 들어봄 / 학부모 문의에 근거 없음 / 보강 부담) +
   파이프라인 한 줄 프리뷰(수업 → 자동 녹화 → 음성인식 → 리포트).
2. **자동 녹화 딥다이브**: 자동 시작 → 클라우드 저장 → 앱 내 재생. 녹화 재생 모의
   UI. 신뢰 요소(워터마크 · 다운로드 차단 · 저작권은 기관과 강사에게 — 기존 FAQ 팩트
   재사용).
3. **음성인식 → AI 리포트 (심장)**: 60분 수업이 읽을 수 있는 리포트로. 음성
   파형/타임라인 → 리포트 카드 생성 애니메이션. 모의 UI는 "예시 화면" 라벨 명시.
4. **원장 활용 시나리오 3장**: (a) 강사 품질 관리 (b) 학부모 응대 (c) 결석·보강.
   에디토리얼 카드 3단.
5. **신뢰 요약 + CTA**: "녹화는 쌓이고, 리포트는 학원의 자산이 됩니다" + 미니 FAQ +
   상담 신청 CTA.

## 정직성 가드레일

- 녹화 보존 기간·용량, AI 리포트 요금제 포함 여부는 **미확정 → 페이지에 단정하지
  않고 상담으로 연결**한다. (포지셔닝 철칙: 가격·수치 단정 금지)
- 리포트 모의 UI는 "예시 화면"으로 라벨링. 실제 리포트 예시(스크린샷/출력 텍스트)
  확보 시 교체한다 — 후속 자산 태스크.
- 카피는 `lib/classin-positioning.ts`("수업 시스템 OS") 톤과 정합.

## 구현 범위

- `app/product/ai-report/layout.tsx` — `createPublicMetadata`(canonical) + JSON-LD
  (WebPage · Breadcrumb · FAQ)
- `app/product/ai-report/page.tsx` — "use client" 5섹션, DESIGN.md 팔레트, 모바일
  우선, `prefers-reduced-motion` 존중
- SW 탭: "데이터 & LMS" 기능 카드 리스트 아래 진입 버튼 (TrackedLink)
- HW 탭: `AfterClassSection` 카드 그리드 아래 진입 버튼 (TrackedLink)
- `app/sitemap.ts` 등록
- 계측: 모든 CTA는 `TrackedLink`/`trackEvent`(`click_cta`) — 진입 버튼과 페이지 내
  상담 CTA 모두

## 비범위 (후속 백로그)

- 실제 리포트 예시 자산 교체 (실물 확보 후)
- 기능 딥다이브 시리즈 템플릿화 (2호 페이지가 생길 때 판단)
- 챗봇 선제 말풍선 페이지 컨피그 추가 여부
- 이 페이지 경유 리드의 소스 세분화 태깅 (현재는 click_cta destination으로 추적)
