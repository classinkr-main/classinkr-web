# KR Team × 매출 장부 역할 재배분 설계 (v2)

- 날짜: 2026-07-16 (v2 — 목업 검토 후 방향 수정)
- 상태: 설계 승인됨 (목업 Phase A v2 진행 중)
- 대상: `/admin/branch` (KR Team, `BranchDashboardClient`) + `/admin/branch/ledger` (매출 장부, `SalesLedgerWorkbench` + `components/admin/branch/ledger/*`)

## v1 → v2 변경 요지

v1(완전 탭 통합)은 목업 검토에서 기각. **매출 장부는 방대하고 중요해서 독립 화면으로 유지**하고, 대신 두 화면의 **역할을 재배분**한다:

> 시각화(보는 것)는 전부 KR Team으로, 수치 검수·입력(만지는 것)은 전부 매출 장부로. 서로는 링크로 오간다.

## 확정 결정 (v2)

1. **사이드바 2항목 유지**: KR Team / 매출 장부 둘 다 그대로. 병합은 콘텐츠 레벨에서만.
2. **장부 → KR Team으로 이동하는 것**:
   - 장부 DSH 렌즈의 **시각화**(누적 흐름·주차 차트) → KR Team **개요 탭**에 흡수
   - 장부 **KPI 렌즈**(활동 병목·담당자) → KR Team **파이프라인 탭**에 흡수 (기존 KPI 아코디언 아래 섹션으로, 탭 신설 없음 — 4탭 유지)
3. **장부 DSH 렌즈 재구성**: 시각화를 내보낸 자리에 **수치 상세 그리드** 신설 — 매출시트 1.DSH 구조에 충실 (Goal/Status × Software/Hardware × New/Renew × Direct/Channel 행 계층, 연간·분기·월별 수치 열, 비율). 검수용 밀도 높은 표.
4. **장부 KPI 렌즈 제거**: 자리에는 "KR Team 파이프라인으로 이동됨 →" 링크형 안내만.
5. **링크형 이동 (크로스 링크)**:
   - KR Team 개요 누적 흐름 카드 → "수치 검수 → 장부 DSH"
   - KR Team 파이프라인 → "딜 수치 편집 → 장부 REV"
   - 장부 헤더 → "대시보드 보기 → KR Team"
6. **장부 REV 렌즈는 변경 없음** (매트릭스 검수·인라인 편집·TSV·초안 큐·주간 마감 그대로).
7. **신규 합성 화면은 HTML 목업 먼저** (v1과 동일 원칙): 개요+DSH 시각화, 파이프라인+병목 렌즈, 장부 수치형 DSH — 3곳이 목업 대상.

## 화면별 최종 구조

### KR Team `/admin/branch` (탭 4개 유지)

| 탭 | 내용 | 변경 |
|---|---|---|
| 개요 | KPI 그리드·히어로 게이지·딜믹스·**매출 누적 흐름(장부 DSH 시각화 흡수, 기존 회계 로드맵과 통합)**·다가오는 딜·캠페인·HW | 합성 → 목업 |
| 파이프라인 | KPI 아코디언 + **활동 병목·담당자(장부 KPI 렌즈 흡수)** + 테이블/칸반 | 합성 → 목업 |
| 히트맵 | 그대로 | 없음 |
| AI 인사이트 | 그대로 | 없음 |

### 매출 장부 `/admin/branch/ledger` (렌즈 3→2 + 링크)

| 렌즈 | 내용 | 변경 |
|---|---|---|
| DSH | **수치 상세 그리드로 재구성** (시트 1.DSH 충실 — 검수용) | 재구성 → 목업 |
| REV | 매트릭스 검수·초안 큐·주간 마감 | 없음 |
| KPI | 제거 — "KR Team 파이프라인으로 이동" 링크 안내 | 제거 |

- URL·역할(roles)·데이터 경로·API 변경 없음. 이 작업은 프론트 콘텐츠 재배분.
