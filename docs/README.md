## 6. Operating Rules

- 한 제품 영역에는 `기준 문서`를 하나만 둔다.
- 구현 순서는 이니셔티브당 `로드맵 문서` 하나에 모은다.
- 사고/장애 문서는 `archive/`에 두되, 현재 상태처럼 읽히지 않도록 역사 기록으로 표시한다.
- 문서 링크는 항상 repo-relative 경로만 사용한다.
- 브랜치명, 로컬 절대경로, 실제 비밀번호 예시를 기준 문서에 남기지 않는다.
