## 주제: 클래스인으로 수업 준비 하기 장소: 목동 클래스인 코리아 하이브리드 룸 (온,오프라인 하이브리드 진행)

선생님의 하루 중 가장 아까운 시간은 언제인가요? 많은 분들이 '**수업 자료 만드는 시간 **'이라고 답하십니다. 수업 자료를 찾는 것 부터 시작해서 프린트까지 하다 보면 벌써 수업시간이 되셨을 겁니다.

그래서 이번 라이브 설명회의 주제를

**' 효율적인 자료 준비 방법'**

으로 잡았습니다.

자료 유형별 활용법부터 AI 자동 변환 프로그램 시연까지, 클래스인을 **200%** 활용하는 방법을 **핵심 내용 **만 정리해 공유합니다. 함께 보실까요?

### PPT — 쓰던 그대로 됩니다

PPT는 기존 컴퓨터에서 쓰시던 방식 그대로 작동합니다. 페이지 전환, 펜 판서, 애니메이션 모두 정상 지원되고, 음성 파일도 드래그 앤 드롭으로 넣으면 바로 재생됩니다. 별도의 학습 없이 바로 사용하실 수 있습니다.

![제 2회 클래스인 세미나 ㅣ 클래스인 200% 활용하기!](/images/blog/naver/naver-2026-07-13-제-2회-클래스인-세미나-ㅣ-클래스인-200-활용하기/image-03.png)

### PDF — 원장님 요청으로 탄생한 '판서 저장' 기능

학원의 90~95%가 사용하는 PDF. 이날 가장 큰 호응을 얻은 것은 원장님들의 요청으로 새롭게 개발된 **판서 포함 PDF 저장 기능 **이었습니다. 수업이 끝나면 판서가 그대로 담긴 PDF를 선생님이 다운로드할 수 있고, 학생은 열람만 가능하고 다운로드는 불가능합니다. 복습은 챙기면서 소중한 학원 자료의 보안까지 지키는 설계입니다.

![제 2회 클래스인 세미나 ㅣ 클래스인 200% 활용하기!](/images/blog/naver/naver-2026-07-13-제-2회-클래스인-세미나-ㅣ-클래스인-200-활용하기/image-04.png)

### AI 기반 EDB — 문제 배경을 AI가 지워드립니다

EDB는 AI가 문제 이미지의 배경을 깔끔하게 지워, 판서에만 집중할 수 있게 해주는 기능입니다. 기존에는 사람이 직접 하나하나 작업해야 해서 시간이 오래 걸렸던 일입니다. 문제 한 개씩 페이지를 넘겨가며 판서할 수 있어, 수업의 몰입도와 퀄리티가 확실히 달라집니다.

![제 2회 클래스인 세미나 ㅣ 클래스인 200% 활용하기!](/images/blog/naver/naver-2026-07-13-제-2회-클래스인-세미나-ㅣ-클래스인-200-활용하기/image-05.png)

### EDU · EDX — 웹을 수업 안으로

EDU는 브라우저를 수업 자료처럼 바로 열어 쓰는 기능으로, 웹 콘텐츠를 즉시 수업에 연결할 때 편리합니다. EDX는 학생 개개인에게 브라우저 권한을 부여해 학생이 직접 웹 활동에 참여하고, 선생님은 각 학생의 화면을 실시간으로 확인·관리할 수 있습니다. 온라인 수업 참여도를 끌어올리는 데 특히 효과적입니다.

### AI 기반 EDB 자동 변환 프로그램

기존 EDB 제작은 문제를 하나하나 캡처하고, 배경 제거를 위해 별도 프로그램을 반복해서 써야 하는 번거로운 과정이었습니다. "더 빠르고 고품질로 만들 수 없을까요?"라는 원장님들의 요청에, 클래스인 코리아가 **자체 개발 **로 답했습니다.

사용법은 간단합니다. PDF, 이미지, 한글(HWP) 파일을 업로드하면 AI가 문제를 자동으로 인식하고, 배경을 제거해 IDB 파일로 변환합니다. **빠르면 10초, 평균 1분 미만.** 흑백 전환과 AI 업스케일링으로 자료 품질도 높일 수 있고, 문제별로 자동 인식되어 수업 때 한 문제씩 넘겨가며 쓰면 됩니다.

국어·영어처럼 지문이 긴 과목도 통으로 변환 가능하고, 모든 과목에 동일하게 적용됩니다. 한 번 만든 자료는 반복 사용할 수 있고, 학생은 수업 후 언제든 자료와 판서를 다시 확인할 수 있습니다.
