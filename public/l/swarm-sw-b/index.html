숙제 AI 채점

제출된 숙제를 AI가 먼저 채점해 초안을 붙입니다. 강사는 그 초안을 보고 고치거나 확정해서 학생에게 돌려줍니다.

채점 결과는 강사가 확인한 뒤에 학생에게 나갑니다.

03연동

모든 일을 대신한다고
말하지 않습니다

결제, 오프라인 출석, 고급 리포트는 학원 운영 방식에 따라 지금 쓰는 시스템을 두고 API 연동이나 맞춤 리포트로 나눠 설계하는 편이 정직합니다.

  1. 1단계

    앱 푸시로 안내 정리

    Classin 앱 알림으로 수업·과제 안내 업무부터 옮깁니다.

  2. 2단계

    운영 데이터 가져오기

    데이터 구독과 코스·수업 조회 API로 지금 시스템에 붙입니다.

  3. 3단계

    필요한 것만 따로 설계

    SDK, 가상계정, 수업 중계는 공식 API 문서를 기준으로 별도로 잡습니다.
